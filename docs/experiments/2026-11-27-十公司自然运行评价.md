# 十公司标准开局的全员自然运行评价

对应总体设计的 V16–V18。采用常规固定资本开局 `world-ten-company-autonomy`，使用虚构公司、真实交易簿及有限账户。开放式基金、成组制造模板变更和人为安排股权认购的专项结果单独列示。

## 开局与截止

| 样本 | 世界时间 | 用途 |
| --- | --- | --- |
| 校准 A | 第 0–90 天 | 检查人物是否能理解可见材料及合法动作，记录经营、传播与市场在同一世界怎样发生。若出现结构性故障，保留这次结果。 |
| 评价 1、评价 2 | 各第 0–180 天 | 在相同冻结代码、章程、初始资产、提示、模型路由和日历上独立开始，分别取第 90、180 天截面。评价开局各自创建，不继承校准人员的笔记、持仓或董事会决议。 |

每个样本记录实际 Git 提交、开局档摘要、模型与路由、请求输入及回执、开停原因。61 名自然人全部依本人当时的资格进入调度；系统刊发身份沿其规则运行。谁任经理、谁采访谁、是否下单均由角色和规则产生。实验期间不人为任命、补现金、增加对手报价、指示召开会议或注入成稿。第一轮分析前锁定评价配置。若评价暴露硬故障，保留该轮及截至故障时的原始记录，修复后另编号。

## 按确认记录计算

- **人物和注意力**　统计实际受邀与发出请求的人数、距离上次决定的时间、等待期限、完成阅读、来源更正及后续选择。分开计数技术拒绝、业务拒绝和自主等待。同人的多次选择不能当成独立样本。
- **公司与银行**　逐家核对有效任职、实际表决、预算和到期，区分活动意图、签约、收货、收入、应收、实收及期末库存。银行看实际发放、现金或准备金、债务履行与处置。季度经营差异要结合电站现存设备、药研进度、陈酿历史库存与贮存期解释。
- **信息**　逐版记录独立根、首次公开时点、实际读者、正式媒体发行与平台转述。邀请、投递、读完、相信和按该信息行动各自计数。匿名私证只在上帝审计中查实，公开报道的转载不重复计作独立第二来源。
- **证券和基金**　从真实委托、成交、撤单与拒单计算活跃证券、对手方集中度、同一对手重复成交、挂单剩余量及无成交时段。基金研究、确认目标、审核、报单和成交各自计数。无成交时记录是否休市、无报价、报价未交叉、资金或持仓受限，或没有人愿意下单。
- **财产**　用交易现金腿、份额或股份变动、实际授信和资本流核算，报告总现金及逐户差额、缺价与不适用状态。基本收益和回撤按流前流后净值计算。同一资金桶的可买额与可取额分别查验。
- **实验成本和恢复**　记录每个实际请求的供应商身份和可取得的 token 用量。缺少实付费用时注明未知。中断点核对在途回执、待执行任务和人物的下一次复查时间；成功重开不增加既有模型请求。

按总体基线第 9 节，主要行为比较要求技术失败为零。到达目标但发生技术失败的样本单列为稳健性轨迹，逐次列出故障、受影响人物和实际后果。两份预定评价均须公开结局，保留异常和提前终止，不补跑直至挑到预期结果。

在每个实验日截止后按同一口径汇总，在两个评价样本中同时报告零值、分歧和失败。两次轨迹不足以估计稳定总体分布。涉及“信息造成交易”之类归因时，需另有只改变该信息的同前缀对照。[总体设计基线](../design/总体设计基线.md) · [当前实施看板](../CURRENT_IMPLEMENTATION.md)

封卷后可从仓库根目录执行 `python scripts/audit_ten_company_run.py <world.journal> <新输出文件.json>`。它从开局逐帧检查物理摘要、相邻状态摘要和世界时钟，按有实际记录的实验日输出逐账户现金、成交量额、委托回报、实际读完及决定结算。实验日从 0 计，恰在零时的事件归入新日。派发记录与供应商实际收到的请求分别核对。完整状态另用对应冻结版 Java 严格重开。

## 首次校准后的阅读工时修订

第一份 v2 校准在第 13.001 秒因供应商空正文停止，留下 83 次完成阅读。实际工时分为 0.5 秒、1 秒和 10 秒，覆盖的文件长度相差很大。新校准及其两个评价采用相同的 v3 阅读政策，从独立开局重新开始。每个新发布的版本按正文计算工时，既定更长的阅读时长仍有效。每分钟 300 个阅读单位是实验设定。汉字每字一单位，连续的非汉字字母和数字合计一单位，标点与空白不计。这个口径处理正文中也会出现的账户标识和数字。目录只向本来获准接触该版本的人列出阅读时长。人在完成前仍看不到正文。

中文句子眼动实验第二组纳入 24 名大学生，正常呈现条件平均每分钟 334 字。该样本给出阅读时间数量级的参照。这里采用同一速度对所有人物和文类做基准试验，缺少专门阅读财报和核对账目的实测速度。宏观评价不把本参数拟合为真实市场人群分布。[原研究表 2](https://pmc.ncbi.nlm.nih.gov/articles/PMC2662925/)
