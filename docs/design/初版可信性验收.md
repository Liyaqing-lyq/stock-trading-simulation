# 初版可信性验收

来源：用户要求按总体Plan持续完成最高质量初版，使世界合理、可接受质疑。本文细化总体设计基线的证据门槛，不追加新产品范围，不用“最高水平”替代可检验条件。状态随代码、真实运行记录更新。

## 判断原则

1. **机制正确性**：资金、股份、物量、权利、时间的变化有唯一原因与权威记录；错误请求由Java拒绝。测试通过只证明所测机制，不证明角色像真人。
2. **行为合理性**：角色看到什么、承担什么成本、能做什么、为什么拒绝或不行动，都可追溯；行为分布通过独立实验评估，不能由几条看似合理的模型发言证明。
3. **经验有效性**：未经现实资料约束/校准的参数明确标实验假设。校准与评价分离，保留失败样本与反例，不为复现目标价格同时倒调所有条件。
4. **可反驳性**：重要主张必须附复现入口、适用范围和能使其失败的反例。独立审查本身也需接受源码和证据纠正。

## 必须关闭的门槛

| 领域 | 硬性证据 | 行为或假设的独立评价 |
| --- | --- | --- |
| 资金、证券与物量 | 从真实事件独立复算，逐主体账平、跨主体转账成对；冻结/尾差/失败原子性明确；不复制资产 | 外部需求与付款参数须披露，不能用总现金守恒代替完整经济解释 |
| 公司与治理 | 十类既定机制与生命周期逐项可运行；经理不能自报进度利润；任免/否决改变真实授权；签约、履约、验收、付款权、收付各有触发 | 预算/考核/需求冲击作敏感性对照；不保证董事会一定有效或公司必定获利 |
| 银行与信用 | 按基线完成存贷、跨行/托管、还本付息、减值核销、救助处置；资本与流动性分别检验；失败有真实后果 | 违约/回收等实验参数与样本范围明确；不能以普通应收逾期冒充完整银行 |
| 信息与社会过程 | 发布、投递、标题、全文阅读、记忆、相信和行动分开；私源权限、转述同源、更正版本、离职/退群边界有联合反例 | 信息传播、偏信、遗忘与趋同报告多次运行分布；不声称文本泄密能被普遍自动检测 |
| 时间与注意力 | 真实正耗时、单焦点/并发约束、观察和完成两帧复核；预算不双占/漏扣；截止同刻规则固定 | 每日活动配额、阅读成本等是否改变行为需实测；已有时间约束不等于已完成全部注意力模型 |
| 市场与无行动 | 冻结交易规则下价格时间优先、被动价、可卖批次、自成交、拒绝与撤单可复算；无买方/无卖方可合法无成交 | 全员趋同不靠暗补现金/强制交易修饰；行情统计与交易动机分开呈现 |
| 恢复、历史与分支 | 全量快照逐帧校验已存在；后续历史浏览/检查点产品入口/独立分支、旧版本缺失及迟到回调需分别验收 | 对照实验运行隔离，重放不偷偷发起新模型调用 |
| Web与交付 | 同时点数据、God/人物权限一致；新档能走真实输入到业务结果；故障/拒绝/未知明确可见；PR review、文档、评分映射齐备 | UI不把模拟、预置、脚本验证、真实模型实验或现实数据混为一类 |
