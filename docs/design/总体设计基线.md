# 股票世界总体设计基线 v0.1

日期：2026-11-05。状态：设计复审后形成的实施依据草案；不是功能完成记录，也不是完整复刻中国市场的承诺。

用户已经确认的方向保留；本文补充的具体默认规则属于本轮设计建议，可通过版本化决定修改。参数试验可以继续，但开发者不能各自解释资金、权限和时间等共同语义。

## 1. 阅读顺序、目标与边界

规则优先级：用户最新明确决定与仓库协作要求 → 本基线的共同语义 → 专题设计中的细节 → 历史研究建议。课程原始要求仍是交付约束；发现冲突应记录，不能用新设计默默取消课程要求。`docs/02`、`docs/03` 描述现有实现，不自动成为扩展世界的目标契约。既有完成状态必须结合当前代码和真实验证记录判断。

| 已确定方向 | 本基线采用的边界 |
| --- | --- |
| Java 核心必须保留 | 账目、交易、世界时间、权限与行为执行留在 Java；保留 JavaFX 课程交付，Web 工作台继续作为主界面候选 |
| 真实机制、虚构身份、允许历史偏移 | 现实资料用于研究和参数约束；角色不直接接触原型映射、原始文件名和现实公司链接 |
| 多公司与机构四岗 | 公司池保留十类机制；研究员、经理、风控、执行员独立决定，共用获授权的产品账户，不各复制一份基金资产 |
| 公司治理与银行 | 用户可见首版必须有定期董事会考核；银行有资金、资本、信用和治理约束，可以失败 |
| 自主媒体、社交和记忆 | 调查与接触有时间、资源、对方意愿和信息范围；首版含遗忘、偏信、习惯变化，不伪造过去经历 |
| 白色、清楚、可查的界面 | 市场、股票、公司、账户、人物机构、信息与世界关系有独立入口；上帝观察与角色操作分开 |
| 模块可增删改复制 | 支持同类实例配置和组合；全新机制需要实现并声明能力，不承诺任意需求零改动 |

十家公司不是封闭经济，也不是必须全部连接的供应链。重点主体完整记账，外部部门采用有约束的聚合模型，跨边界资金和物量可追踪。没有合同的公司也可通过共同需求、成本和投资者形成联动。

首轮实现不引入微服务、任意第三方代码热加载、完整家庭生活系统或全市场全部资产。暂不支持的行为要明确拒绝，不能由 LLM 文本临时补出一个能力。

## 2. 身份、资产与权威记录

| 对象 | 持有什么 | 不能混同 |
| --- | --- | --- |
| 人物 | 经历、信念、关系、日程、社会身份 | 不等于一个证券账户，也不等于其雇主 |
| 组织 | 岗位、组织档案、预算、制度、治理授权 | 基金管理公司自有资产不等于基金产品资产 |
| 财产主体与账户 | 资产权属、负债、冻结、流水 | 查看账户不等于有交易权；经理个人工资不进产品账 |
| 证券与发行人 | 股份总数、权益登记、流通限制、公司行为 | 股价、市值、公司账面权益和公司现金各不相同 |
| 角色任职 | 人物—组织—岗位—有效期—权限 | 退职终止组织访问与操作权，不抹除其个人经历 |
| 信息对象 | 原文版本、作者、受众、时间、引用 | 公告、报道、观点、世界真值不是同一种记录 |

每次经营、成交、收付款、授权、发表或投递都有唯一事件标识；原文与账务结果不可原地覆盖。纠错通过关联更正或冲正事件实现。普通角色不能读取全局审计序号、隐藏实体数量和私密来源标识。

所有金额记账沿用 BigDecimal（金额 2 位、成本价 4 位），数量使用 long。计算中间精度、最终舍入规则和尾差归属随规则版本固定；不能按每个页面自己的四舍五入结果回写账目。利息按合同日计数约定累计，入账时舍入；费用按声明的订单/日汇总范围计算，不能每次部分成交都重复收最低佣金。

## 3. 开局、外部部门和银行账户

### 3.1 开局不是第一天随机发钱

开局清单必须包含：全部财产主体、银行账户/托管账户映射、现金来源、发行股份与所有者、初始负债、资产成本、初始估值、合同、预算、授权和规则版本。

- 初始股份全部分配给可识别的持有人，包括聚合的创始股东与外部持有人；流通、锁定、库存股分别列示。所有持有人数量之和与已发行股份核对，不能让每个新 Agent 独立生成底仓。
- 初始资产是实验的历史禀赋，按开局资产负债表录入，不假装开局刚发生募资。投资者持股不是公司库存；二级市场买卖款归卖方，公司不能因自身股价上涨自动收到现金。
- 运行后新增资金、发行股份、进入新投资者必须对应转移、真实认购、借款或明确外部注资事件。复制配置不复制财产。
- 外部持有人不运行 LLM 也必须持有真实库存；外部交易者参与订单簿时，同样受现金、可卖数量和权限约束，不能做无限买卖的兜底盘。

### 3.2 唯一的现金与托管口径

推荐首轮采用简化托管模型：证券账户的现金是客户托管资金的明细权利，托管机构在结算银行有对应资产。用户资产视图只计客户的那份权利一次；托管汇总账用于对账，不能再加成客户第二份资产。银行的存款负债、准备金、证券客户现金不是可以相加的三份“世界财富”。这是一种模拟简化，不声称完整复制中国结算全部制度。

从个人银行存款转入证券账户，先减少原存款并增加对应托管明细；跨行时另有结算资金转移。付款待处理、已冻结、成功、失败分开；失败不能只扣付款方或只加收款方。存量账户迁移到银行体系时生成一次有对账证据的迁移，不再次发放其现金。

银行直接贷款与背景贷款组合互斥计入：将聚合借款人提升为独立公司时，要转出原组合敞口、减值及相关现金流，再转入明细；不新增一份贷款。直接/背景客户共享授信和结算约束。

贷款本金形成贷款资产与存款负债，偿还本金减少相应余额；利息、损失、费用另计。准备金与资本不能互相替代。[英格兰银行的货币创造说明](https://www.bankofengland.co.uk/explainers/how-is-money-created)用于机制核对，不用于代替中国银行监管规则。

### 3.3 外部约束与银行门槛

客户群有需求预算、供应商选择、付款与违约规则；供应商有容量与交期；融资来源有价格、期限和容量。外生收入必须标来源，宏观冲击本身不能直接充值。单币种人民币记账作为首轮默认，外汇先影响合同折算/成本条件；未实现外币子账前不能宣称支持真实多币种资金交易。

银行启动前加载完整且可计算的规则档案：规则来源与生效期、适用分档、资本层级/RWA/杠杆分母、流动性与期限缺口、集团敞口、表外承诺、减值方法、限额和触发措施。缺字段或未实现指标时拒绝启用该档案，不能默认通过或填零。简化实验档案可以缩小覆盖范围，但必须明确列出省略项；界面显示“实验规则”，不能标为监管合规。

救助不是银行自己的权限。应急融资有提供者、额度、期限、担保与偿还义务；增资有出资方与股权变化；不能支付时允许违约或进入预设处置。具体阈值沿银行专题的规则分档研究确定，本基线不虚构一套通用现实参数。

## 4. 公司、董事会和信息产生

每个公司模板必须提供可执行的机制说明：开局资产负债、业务状态与数量单位、收入确认条件、库存/成本、回款、费用/折旧、投资/债务、可选管理动作、耗时与失败、董事会权限、披露日历和角色可见范围。缺少这张表的“公司”只能是待配置模板，不能以行业名称作为已经实现的经营模块。

推荐先做制造链的完整竖切，再加入工程回款与银行作差异验证，最后逐项扩展其余模板；研究阶段仍保留十类的组合设计。这是实施顺序建议，不删除已经选择的多公司目标。

物量与财务对应：产能不是销量；签约不是收入；交付不必等于收款；收取预付款可产生合同义务；研发/设备支出按模板会计政策处理。必须允许经营利润为正但现金短缺。公司账按资产负债关系对账，股票市值不回写公司账面权益。

董事会每个有效公司均存在，可按配置月度经营复盘、季度正式考核，重大支付/越权风险即时升级。会议具备召集、议题、材料截止、出席、表决、异议、决议、实施与复核状态。推荐首轮普通事项超过全体有效席位一半赞成才通过；关联事项回避，剩余席位不满足预设法定人数时延期/升级，不能自动批准。重大预算、任免、分红与融资使用不同授权清单。该治理规则是虚构章程，不能冒称原型公司的真实议事细则。

考核至少有经营兑现、现金/偿债、风险、披露质量与长期投入；权重事前保存。短期股价不能成为所有公司的唯一指标。董事会决定预算/授权/任免，Java 验证资源与权限；董事会不能凭一句话改利润、抹除债务或把失败研究改成成功。

定期报告从截止期间的经营记录形成，经财务准备和董事会/授权人流程发布。内部真账与对外陈述分开：如场景允许夸大或隐瞒，记录谁对哪些已知内容作了何种公开陈述，保留原账与后续更正。不能用模型幻觉直接修改权威账。

## 5. 证券交易与公司行为

### 5.1 两种规则模式不能混跑

保留现有课程连续竞价模式用于回归；扩展世界使用单独的有版本规则档案，包含交易日历、时段、交易单位、最小价位、价格限制、买入可卖时点、现金可用/可取、费用、停复牌、公司行为和支持的订单类型。不足以实现某一真实市场档案时，称为“简化 A 股机制实验”，不称为全市场复刻。

优先实现限价、现有市价单的明确实验语义及必要时段规则。涨停价限价单可以排队；主动限价单可以吃掉对手盘。五种市价委托、条件单或完整 TWAP/VWAP 都不是产生追涨、排队或踩踏的逻辑必要条件。是否支持某真实委托须另按板块/时段核实。交易所职责是确定性规则执行；治理角色可以提出有权限的市场措施，LLM 不裁定订单是否合法。

上交所 2026 版的价格时间优先、限价申报与除权参考价条款为本轮核读依据；通知同时附有暂缓条文，不能仅凭正文标“全部已实施”。[官方通知与附件](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)

当日买入不可卖的实验规则采用批次/数量台账：可卖量是当前满足出售条件的剩余数量减卖出冻结，而非固定的昨日收盘持仓。卖出消耗对应批次；撤单只释放未成交部分；当日回补的股份不能冒充昨日底仓。现金可交易、可提现、冻结和结算待收付分别处理。

限价单是否成交看其是否跨过当前对手报价，不能仅看是否等于最近成交价；行情变化后最近成交价未必仍在当前买一卖一之间。旧项目记忆中“限价等于最新价永远不成交”的绝对结论不作为扩展规则。例如最近成交价 10、当前卖一也为 10，买限价 10 可以成交。

禁止同一受益账户自成交。首轮相遇时拒绝新单的自成交部分并给出原因，不制造成交量；同机构不同产品不能简单按同一个账户合并。跨主体合谋属于另行实验场景，不是维持市场健康的必要条件。

### 5.2 分红、停牌与退出

分红流程：提案 → 授权批准及公告 → 登记持有人 → 除息/权益处理 → 付款。公司端分红义务、投资者端可确认应收及实际到账分别记账；应收转现金时不再计一次收益。未付款应收有风险和后续减值，不永远按无风险现金处理。

首轮登记截止按权益持仓快照锁定受益人，不能用可卖数量漏掉当日买入/冻结的合格权益；登记后转卖不转移已登记红利。登记仅固定归属，不提前增加投资者净资产。投资者应收首次计入与除息参考价处理，在规定除息开市前的同一批次完成；公司应付按批准流程确认，已确认的总义务不因后续分配到持有人再记一次。付款只结清既有应收应付，登记前撤销/变更方案走版本与重新公告流程。

除息调整的是参考价格及相应涨跌幅基准，实际成交仍由订单形成。拆并股调整股数与成本/参考数据，不保证实际市值不变。登记日、除息日、支付日、精度与零碎权益处理随公司行为类型固定。首轮只启用已完整实现的现金分红；拆并股/配股等未实现前禁止触发，不让长周期事件生成器随机调用。

停牌不是删除公司；退市不是消灭产权；清算不是自动按最近成交价全额退出。分别记录经营、挂牌、交易、偿债和清算状态。最低可用失败路径：停止新增业务/申报，取消适用剩余订单，保留财产与债权，依预设且公开说明的处置规则分配回收款；未启用完整清算模块时停在“待处置”，不伪造最终回收。角色仍可收到到期信息与查看历史。

## 6. 账户收益与图表的唯一口径

存量课程排行榜保留初始权益口径，并明确其适用范围为没有后续出入金的旧模式。扩展模式另报投资收益、资本流和净值，不静默改变同名字段。首轮开局持仓成本设为开局估值；导入历史持仓成本不等于期初市值时，需另报历史成本损益与本次实验表现。

账户净资产 = 现金权利（含冻结，不能重复相加）+ 原始价格估值的持仓 + 已确认应收 − 负债与应付。每一项来自同一截止时点。

| 事件 | 投资表现分类 |
| --- | --- |
| 工资储蓄转入、追加资本、申购、赎回、提现 | 外部资本流，改变规模，不直接当盈利/亏损 |
| 组合股票的股息、利息、价格变化 | 投资损益；不能作为外部注资排除 |
| 交易费、产品承担的费用、融资利息、减值 | 对应损益；费用负担主体和计提时点明确 |
| 同一账户现金买股票、应收红利到账 | 资产形态变化；不能重复记一次收益 |

推荐以每次外部资本流前后的估值切分期间，几何链接期间收益，得到时间加权收益；单位净值采用同样的流量与估值时点。账户净值不能用“后复权股价 × 实际持股 + 已到账红利”计算，这会重复计算分红。复权曲线仅服务价格比较，原始成交用于持仓核算；基准总回报另声明再投资假设。[GIPS 手册 2.A.8、2.A.24、2.B.3](https://www.gipsstandards.org/standards/gips-standards-for-firms/gips-standards-handbook-for-firms/)支持总回报、现金流分段与除息日计提的取舍，项目不据此声称通过 GIPS 合规认证。

有申赎的基金还需份额登记。推荐首轮在规定日终估值点确认、下一规定付款点支付：申请截止前的有效请求按同一确认前净值定份额；申购款预收阶段计现金与待确认负债，不提前归现有持有人；确认时消除该负债并发行份额。赎回确认同时注销份额并形成应付款，付款只减少现金和该负债。资金不足按产品事前约定排队/比例确认，不能给先到的模型请求抢先全额兑付。份额精度、费用和尾差独立声明（证券股数仍为 long）；未实现时不启用有申赎的产品模板。

待确认申购款不可用于经理投资或其他付款；其利息/费用归属按产品规则单列。排队未确认份额保留原权益与风险，不提前锁定净值，后续依实际确认批次定价；已确认赎回应付款金额固定，不随随后净值变化。赎回请求冻结对应可赎回份额，撤回/部分确认时正确释放，不能同时提交多笔请求重复注销同一份额。

基金净资产 100、100 份，预收申购 100 时新增现金和负债各 100，净资产仍为 100；确认后净资产 200、份额 200、净值 1。再确认赎回 50 份，净资产 150、份额 150，并有应付 50；支付后净资产仍 150，不能再次减成 100。时间加权绩效的外部流量归在份额确认的权益转移时点，现金到账/付款清偿待确认负债或应付款时不重复算外部流量。

举例：净资产 1,000，追加 500，资产价格未变，则规模变为 1,500，投资收益仍为 0。100 股原价 10、每股股息 1，在测试夹具人为固定成交价格为 9 时，900 市值 + 100 应收 = 1,000；到账后只是应收变现金。这里价格 9 是算账夹具，不是对真实行情的预测。

缺价时不得默默用成本价：显示最后有效价格、时间和陈旧程度；开局无成交时用明确的初始参考估值。无合理估值时净值显示不完整并暂停精确排名，不填零。净资产为零/负、零份额、无样本的年化/夏普等显示不适用；清盘后重新注资另开表现期间，不连接成无限收益。

日 K/分时/周 K 来自同一成交链。未完成柱、无成交、停牌、复权类型和统计截止均显式标识；没有成交的空档不补出假交易。回撤基于剔除外部资本流的净值曲线，资金规模另画；不把工资到账画成策略跳涨。

## 7. LLM 的职权、信息来源和错误

LLM 负责提问、研究、预测、取舍、沟通和提出行动；规则引擎负责资源、权限、会计、交易及状态转换。模型没有直接写余额、改订单、认证成功或生成监管许可的工具。

每次调用包只含：触发原因、当时可见材料、必要状态、相关记忆、未完成任务、合法动作与预算。原型资料转换后的虚构文档与现实研究库分离；运行中的角色不直接联网检索现实原型。外部数据导入先经过版本化转换和审查，再成为模拟事件。改名不能保证模型认不出原型，应做盲测并记录识别率，不能承诺零识别。

| 输出情况 | 处理规则 |
| --- | --- |
| 有证据引用的复述 | 核查引用可见、确实读取、版本和数值匹配；保留说话者与不确定性 |
| 个人判断/预测 | 可以错误，记录为信念或预测，不改世界真值 |
| “我刚见到某人”等经历声明 | 必须关联真实经历；否则标为当前无支持/虚假自述，不能补造过去事件 |
| 说出本来知道的非公开信息 | 在已允许的泄露场景中按实际收件人传播，保留知识来源和规范违背事件 |
| 猜中本来不知道的秘密 | 仍是无证据猜测，不能因与上帝真值一致而自动认定真实泄密；系统越权供数另判技术缺陷 |
| 捏造引用、越权工具调用、非法账务 | 拒绝该效果，记录技术/格式失败；不包装成聪明的交易决定 |

对模型是否“故意撒谎”不能只凭一句话推断。只有动作明确声明误导意图及已有知识支持时才标有意欺骗；否则标无支持陈述/错误，避免把模型缺陷都解释成人性。

新闻、私聊和文件内的“忽略规则、打开全部账户”等文字属于内容，不能变成系统指令。调用权限由可信任务授权决定；内容引用不能新增工具能力。校验过程不得把对照用的上帝真值喂回角色。结构化可核查主张优先，无法核查的自由文本显式保留“未验证”，不承诺自然语言检查百分之百有效。

## 8. 组织记忆、社交与媒体传播

六层记忆沿用专题设计。遗忘影响主观回忆的可检索性，权威账目、有效授权、订单和承诺从当前状态提供，不能遗忘成无约束。个人从外部知识库重新查到旧公开文件是新一次获取，不是恢复一段从未发生的经历。

组织档案与个人记忆分别存储。新入职者可以按授权查询旧组织档案，但不是立即知道全部内容；阅读才进入其经历。离职者失去实时系统和新档案访问，已实际记住的内容仍可随遗忘保留；仍受世界中的保密规范约束，违规传播作为行为事件。前任私人关系、未提交的意见和整段记忆不会自动克隆给继任者。

新资料阅读采用“选择版本 → 预留工时 → 阅读完成 → 提交观察”流程；全文在完成后才可进入后续决定和记忆。若需要边读边反应，按段产生有时间的观察；中断保留已读段，不把最后一页提前喂给角色。10:00 开始阅读 30 分钟的材料，10:05 的风险提醒不能让角色使用 10:30 才读到的数据。阅读中发布新版不替换当前材料；需另取新版本。已有个人经历的检索不伪装为一次新的外部调查。

安排阅读前，检索工具仅返回允许的目录/标题/已付出相应阅读成本的摘要；不能先把全文放进模型上下文，再靠提示词要求“假装还没读过”。同一次调用发现需要新资料时，先提交阅读动作，完成后再唤醒下一次决定。

群组默认加入后收到新消息；历史仅在群明示允许、当前身份获授权时查询并产生阅读记录。退出停止新投递，不抹去已经读到的经历。私聊/电话按收件人投递；本人忙碌允许异步排队，预约检查约定时段。对方拒绝、爽约、只回复公开口径都是有效结果，不能自动奖励秘密。

媒体保持专题规定的八类模板与独立采编动作。平台排序、作者选择与读者阅读各有记录：被推荐、看见标题、打开全文、相信、行动是不同事件。只知道标题的 Agent 不能引用未读全文；摘要本身作为有内容边界的新信息对象。

同一原始来源的转载不增加独立证据数。内部审计可保存匿名信源真实映射；读者只看到发布者选择公开的来源描述/可见谱系，不能通过引用 ID 查出匿名者。编辑是否知道真实身份取决于采访共享流程，不默认全组织都知道。更正沿实际渠道传播，没收到的人不会立刻改变记忆。

媒体/机构工时、差旅、订阅等是世界内资源；真实 LLM token/API 费用属于实验成本，默认不从角色证券余额扣钱。角色研究成本由合同指定个人、雇主或产品承担；不得因为真实模型服务贵，就让某人物在模拟里突然破产。

角色学习与实验者评价分流：人物只能根据自己实际获知且结果已成熟的证据更新信任/习惯；董事会按其真实得到的报表与授权资料考核。上帝可用隐藏真值和未来结果评分，但评分不回流角色。每项预测先绑定对象、指标、期限和验证来源，未成熟标待评。模型输出的好坏不能由后台全知奖励在下一轮暗示；重跑实验明确继承或重置哪些记忆。

## 9. 世界时序、公平与失败

推荐默认实验时间模式：观察时点固定，动作有正的模拟耗时；世界推进到依赖点等待所需模型结果。墙钟超时不会自动变成世界中的失业、破产或拒绝接电话。

模型调用前先由程序确定本次决定的最早提交屏障；动作尚未知时，世界不能越过该屏障。模型返回后才按动作类型安排阅读、通话、出行等耗时。决定耗时与执行耗时分开，不能先让世界向前跑，再给模型选出的短动作补记到过去。零成本纯查询也受每轮预算限制，不形成零时间递归。

同一模拟时点采用固定阶段：到期规则/资格与结算变化 → 已排程公开/投递 → 完成此前已启动动作并复核授权 → 生成新观察/唤醒。动作内部按因果依赖排序；独立同级行动采用运行种子生成、事前固定且可记录的公平顺序。交易所接受订单后，仍遵循价格时间优先，不重新随机化簿内排队。连续多步社交不得在同一时刻递归无限执行。

首轮调度精度默认 1 模拟毫秒，用于区分事件先后，不代表阅读或思考只需 1 毫秒。动作完成后新产生的消息/公告最早在下一时间步、并满足其渠道延迟时投递；不能回跳到本时点已经结束的公开/投递阶段。已持久提交的动作结果可进入本时点后续合法观察，跨人物传播仍走实际投递事件。更改调度精度属于运行规则版本变更。

角色收件箱、可见材料和接收位置由世界调度器在预定模拟投递事件中提交；后台异步通知只搬运已确定的结果，不决定角色何时得知内容。投递不等于阅读，仍须满足 §8 的知识获得规则。快照绑定提交版本及截止位置，不能只用时间戳筛选而纳入同一时间戳下后来才提交的内容。调换通知线程速度不改变 Agent 的输入。

同一账户并发命令逐一基于最新余额和任务版本复核；模型提交的是意图，收到的是受理/拒绝/部分成交等实际回报。硬限制不能被治理对话覆盖；策略软限额例外有额度、期限与责任人。

首轮区分三类结果：主动观望、业务拒绝、技术失败。技术失败可按固定次数重试相同快照，超时后走预设回退；迟到结果不能再下单。模型并发队列使用公平配额，记录排队时间、超时和回退分布。角色规模/调用预算作为运行配置显式展示，不静默把一部分 LLM 角色替换成规则角色。

改变真实 API 延迟但保持同一组已记录决定，未触发超时分支时结果应一致；如果触发超时，实验已改变，必须计入质量报告。研究运行默认要求技术失败为零才进入主要行为比较；存在失败的运行保留为故障/稳健性样本，不能偷偷删掉不好看的结果。

暂停：停止推进世界时间，不收新行动效果；在途返回只入等待区，恢复后复核。正常结束：关闭新任务入口、处理在途决定、撤销适用挂单并释放资源、保存终态。紧急停止：保留最后持久确认点，明确尾部未确认事件，不伪称正常收盘。长期行动的取消、返程和已花成本沿专题 §9.5 执行。

## 10. 持久化、恢复与契约

首轮采用单进程、单一世界变更调度器；模型推理和观察并行，经济状态变更串行提交，沿用引擎锁 → 账户锁。模型/文件 I/O/广播均不得持有撮合锁。不要为了可插拔引入跨服务分布式事务。

每个命令绑定运行、发起身份、授权版本、目标版本和幂等标识。同一标识同内容返回原回报；同一标识不同内容拒绝。超时或重连后先查结果，不能盲重试再发一笔钱。业务失败和访问不可见的错误投影不得泄露隐藏对象存在性。

推荐提交协议：在唯一写入调度下校验并形成不可变变更批次 → 锁外持久提交事件、账务变更及待投递回报 → 在原锁顺序下应用到内存 → 发布新版本快照并异步投递。候选形成到应用之间禁止其他世界写入；观察者只看到完整旧版或完整新版。磁盘提交失败则不应用、不确认成功并暂停写入；提交后进程退出则从已持久批次恢复。现有直接变更的撮合 API 需要适配，不宣称已有此能力。

事件与待投递回报一并持久化；消费者按标识去重。因此“已入账但未广播”可补发，重复广播不能重复入账。CSV 是导出和课程验收材料，不能作为完整恢复源。

检查点包含：全部财产/证券/冻结、订单队列和优先序、世界事件队列、合同与义务、公司/银行状态、角色权限/记忆/习惯/日程、消息投递与阅读位置、任务版本、去重记录、随机流状态、模块/规则/资料/模型配置版本及已确认事件位置。检查点在完整提交边界生成并验校验和。

历史观察重放实际记录，不重新调用模型。继续运行从完整检查点恢复；在途未完成模型请求在检查点标识为待重建工作，沿原观察快照重新请求并防重复执行，未来输出可能不同，不能保证与未中断实验逐字一致。从历史开分支生成新运行 ID，保留父运行及分支点，资源隔离；新决定和随机路径不冒称原实验回放。

每次模型尝试还绑定运行 ID、动作 ID、尝试 ID 与恢复代次；仅当前有效尝试可提交。旧进程/旧分支迟到回调只能归档，不能写入新分支。恢复继续追加原日志；不得经过会截断旧 CSV 的新建流程。已记录但尚未应用的决定应恢复该记录，不重新问模型。

观察契约先保留进程内语义；Web 接入时再据此写可执行请求/响应规范和测试。服务端从可信身份生成快照，所有联动面板共享同一快照；游标过期可完整重取。慢消费者不阻塞撮合，但不能静默丢审计数据；审计存储满时暂停世界，纯 UI 推送可合并并提示重新同步。

## 11. 可插拔、升级与复制

每个模块声明：能力类型、配置版本、依赖、必填资源、支持的动作/事件、观察字段、状态版本和退出策略。公司经营实现、媒体流程、角色策略、视图面板各司其职，不共享可随意修改的全局状态。模板默认只能组合已注册且通过契约检查的能力。

生命周期固定为：草稿 → 校验通过 → 等待安全点 → 生效 → 暂停/退役。只有未投入运行且无引用的草稿可物理删除；有历史、债务、持仓、消息或合同的对象保留退役档案。删除面板只改布局。

安全点要求无半提交批次，受影响任务/订阅已处理，资源与依赖迁移校验通过。公司模板升级默认只影响新实例；运行实例升级需显式指定版本和迁移结果。迁移失败保持原版本或明确暂停。旧模块和数据格式需保留到其运行的回放/恢复义务结束；找不到版本时明确“只可查看导出，不能继续”，不能装最新版本假装恢复。

一次“升级全部引用”在声明的同一运行范围内全成或全不成：先准备并校验所有目标迁移，再整体切换版本；不得迁移到第二个失败却留下第一个已升级。不同运行分别提交并报告各自结果，不承诺跨运行原子事务。

配置副本新 ID、零新增资本、无原人物经历。检查点分支可以沿用实验初始资源，但属于不同运行；不能把分支账户再导回原世界。外部聚合对象提升为详细对象是迁移，必须移走原聚合量，不是复制。

## 12. 白色界面的审计与使用规则

所有页面顶栏固定：运行、世界时间、实时/回看、观察身份、当前账户和数据状态。首屏显示问题所需摘要，详情逐层进入；“所有信息可查”不等于同时铺满屏幕。

| 页面 | 必须回答的问题 | 默认图表 |
| --- | --- | --- |
| 市场/股票 | 价格、成交与公开信息怎样变化 | K 线、成交量、盘口、事件标记 |
| 公司 | 经营如何兑现，现金为什么变化，董事会怎样行动 | 业务进度、财务桥接、现金/债务、决议时间线 |
| 账户 | 钱归谁、持有什么、表现如何、哪些任务未完成 | 资产配置、净值/回撤、资本流、目标与实际仓位 |
| 人物/机构 | 谁能做什么、读过什么、正在做什么 | 岗位与授权、活动时间线、联系人、交接 |
| 新闻/讨论 | 谁说了什么、依据什么、谁收到或评论 | 原文/更正版本、评论、可见传播路径 |
| 世界 | 谁依赖谁，这条关系是什么 | 分层局部关系图、条件暴露矩阵、边的数量/金额/时点 |

世界图默认先选经营、资金、股权、任职、社交、传播之一，再看选中对象一至两跳；大图按部门聚合，可搜索展开。合同金额、付款额、证券持仓比例和“可能受同一因素影响”不能画成无类型的同一种边。每条边有方向、依据、有效期、数值单位和可见范围。资金桑基图只有在所选期间及统计口径可对账时展示，不能混入贷款余额和累计支付。

股票的“我持有多少”、账户的“这只股票占净资产多少”、公司的“此账户占发行股份多少”是三个字段，不能共用一个百分比。重大事件榜按声明的覆盖范围和排序方法显示；上帝能看内部事故，不代表该事故已成为市场公开热点。

上帝审计显示实际输入材料、检索结果、结构化意见、动作和后果，不要求模型隐藏推理链。影响链连线代表记录的先后/引用/执行关系；“新闻导致股价上涨”必须有对照实验，不能仅凭时间接近自动标因果。

身份切换清理缓存、订阅、抽屉和导出上下文。个人模式数据从服务端裁剪，不能只在 HTML 隐藏。上帝查看后的人工接管默认创建有标记的新分支，避免把已知秘密的人工订单混入原行为实验；同一运行的干预必须明确记为受干预实验。仅查看不改变运行。

统一显示空状态、无权限、未到时点、断线/陈旧、等待模型、未实现和业务拒绝；不得都显示为 0。保留键盘操作、焦点、表格替代、非颜色提示、图表单位和时间范围。浏览器刷新/断线后恢复选择不等于重启世界；长列表分页/聚合，性能阈值由原型实测确定。

## 13. 验收矩阵与实施门槛

下表是待执行验收规格，不是通过记录。硬性不变量失败即阻止相应功能进入用户可见首版。

| 编号 | 反例/实验 | 必须成立 |
| --- | --- | --- |
| V01 | 复制公司/投资者，再提升一个外部借款人 | 原世界总股份/财产不凭空增加，贷款不双算 |
| V02 | 二级市场成交、银行存款转证券托管、跨行支付失败 | 资金只转移一次，公司不收到二级市场买款，失败两边一致 |
| V03 | 银行新贷款、还本、减值、核销、救助 | 各科目可对账，资本/准备金不混用，核销不重复损失 |
| V04 | 追加 500、现金分红登记/除息/到账 | 资本流不是盈利，分红只计一次，实际价格不强制下跌 |
| V05 | 昨日 100 股，今天卖 60 再买 60，再卖 | 剩余合格库存最多 40（无其他事件），冻结还须另扣 |
| V06 | 涨停限价排队、仅有限价追价、自己撞自己的订单 | 可表达排队/吃单；自成交不生成虚假量 |
| V07 | 新闻含越权指令、猜中秘密、记者引用未读全文 | 不授予新权限，不把猜测认作泄密，不编造证据 |
| V08 | 研究员离职，新人接任，群员加入/退出 | 无自动知识复制，历史实际经历和新系统访问分开 |
| V09 | 角色忘记报道、收到更正、互相重复转载 | 权威账户准确，只有实际接收者更新信息，同源不算独立 |
| V10 | 调换模型网络返回顺序、触发超时、过期回复 | 正常分支不由网络抢跑；失败可见且无迟到重复效果 |
| V11 | 付款持久提交前/后退出；重发同一命令 | 全部或无提交，恢复一致，重复请求不重复记账 |
| V12 | 保存/恢复/分支；缺旧模块版本；推送断线 | 历史回放与继续区别明确，缺版本不假恢复，补取不漏/重 |
| V13 | 停用公司、暂停角色、出差中撤销授权 | 义务/持仓不消失，已花成本不回滚，剩余任务按规则结束 |
| V14 | 上帝切个人后搜索/导出/回看/点匿名来源 | 全部入口相同权限，不泄露隐藏身份/数量/未来数据 |
| V15 | 各页查看同一账户；停牌缺价；无外部入金模式 | 净值一致、估值状态明确，旧课程收益口径可回归 |
| V16 | 经营现金短缺、董事会否决/回避/更换经理 | 不靠新闻或投票造利润；治理确实改变后续动作权限 |
| V17 | 全员同时看多、流动性枯竭、弱者亏损退出 | 允许一致/无成交，不暗增资金或强迫反向下单 |
| V18 | 保留场景输入，对照不同信息/记忆/身份机制 | 多次独立运行，报告失败与不确定性，不用演示剧情证明涌现 |

实施顺序建议：① 核对课程基线及已知静态风险；② 世界时间、身份/账户、账目与可恢复记录；③ 一家完整公司（含董事会）+ 四岗机构 + 两类媒体 + 普通投资者的端到端竖切；④ 工程/银行差异机制、其他公司模板与跨公司配置；⑤ 白色工作台接真实数据与完整权限；⑥ 行为与压力实验。观察页可在各阶段增量接入，不等全部模块完成后才检验 UI。

用户可见的首版需完成其宣称启用的全部链条，包括董事会、遗忘/偏信/习惯、独立机构岗位和真实图表来源；内部调试版明确标注，不能以少一个岗位或假账户曲线冒充完成。

行为验证与程序正确性分开：会计/权限/时间是硬门槛；自然语言风格、群体分布、市场统计和原型识别率是需实验校准的指标。先用无 LLM 可控夹具验证因果和故障，再固定场景与预算比较角色机制。初始股票价格、外生条件、行为规则不能同时调到恰好复现原股价，再宣称发现真实因果。

每个实验保存运行清单、版本、初始状态、外生输入、模型及提示配置、实际决定、资源消耗和失败比例。校准样本与评价样本分离；先少量试跑估计方差，再定重复次数，报告结果分布而非最佳一轮。自然趋同允许发生；人设不同但资金/约束完全相同不保证长期异质性。

阶段完成继续执行仓库验收要求：PR、至少一名人工 review、AI 标注、对应评分表状态、`scripts/verify.sh --with-gui` 与新机制专门验证、真实输出记录。不要固定声称当前测试数量；以当次输出为准。设计审查/文档检查不替代任何一次运行验收。

旧《A股长期交易与多Agent扩展设计》中的“拟合到指定统计容差才允许合并”“种群必须统计显著不同”“同种子重新调用 LLM 必须同结果”“P2 前必须达到五万 Agent”不再作为本项目实施门槛；它们至多是需重新立项的研究/容量候选。该旧稿按时间可放弃公司/媒体扩展的路线，也不能取消用户现已确认的首版内容。未通过硬性正确性验收不能发布；未得到预期社会现象则如实报告实验结果，不能调参直到好看。

## 14. 仍需通过实验/实施确定的事项

这些是有边界的待验证项，不允许开发时偷偷填成“现实事实”：公司参数与身份资金分布、联系/阅读/遗忘/习惯变化速率、董事会考核权重、银行完整计算档案、模型规模与并发预算、正式图表组件兼容性和性能、真实法规档案的完整覆盖。

不能承诺的结果：模型绝不猜出原型、所有角色永不趋同、每条新闻必然影响股价、每种公司都产生预定行情、任意插件都无需改代码、固定随机种子能复现重新调用 LLM 的文本。
