# M6a 同一截止快照的离线审计观察页

依据总体基线§10/12的增量观察入口。先将已启用世界导出成可离线打开的白色审计页，定位是固定快照观察，不增加角色操作或确定Web为主界面。JavaFX课程入口继续验收；账户、公司、市场、治理的数值必须来自同一WorldRuntime.Snapshot。

- 新增小型Java导出适配器与单文件HTML模板，不引入前端依赖/服务器。导出只读不可变Snapshot/开局登记；不会打开第二个世界日志、更改账目或推进时间。当前G治理施工期间，仅在忽略的logs/observer-preview里准备私有源码/模板，待治理单元冻结后再进入下一代码分支，避免抢源码与target。
- 顶栏显示运行、模拟时间、审计观察身份、固定快照和截止位置；公司、账户、市场、事件独立页签，治理完成后增加董事会。未启用信息/角色/银行不制造页面数据。风格采用亮色极简与数据仪表盘，细边框/留白/对齐数字，克制动效并支持reduced-motion。
- 公司展示真实收入/成本/费用/折旧/利润、资产负债平衡、库存/应收应付与已发生收付款；账户区分现金余额/冻结/可用及各证券持股，股价/市值不混入公司权益。价格无成交时明确开局参考，空成交不补假K线。
- 所有金额/long数量和时点在导出JSON中为十进制字符串，浏览器不以浮点重算账务/净值；Java派生金融数值。嵌入JSON转义HTML敏感字符，动态文本仅用textContent，禁外部网络资源和任意内容执行；不把内部审计页冒充普通角色可见视图。
- 页签、账户筛选、事件筛选/详情可键盘使用；手机/矮屏和打印有可读布局，无只用颜色区分状态。每页明确无数据/未启用/缺估值，而不是填0。
- 验收用正式Demo的真实Snapshot导出，核对35日现金1150/利润50/权益2050/世界现金3600及董事会截止证据；另用超2^53金额/long和HTML注入文本验证精度与文本边界。浏览器真实点击/截图看图，检查窄屏无横向挤压、焦点与空状态。代码通过独立审查/标准GUI+CSV/Javadoc/PR；网页截图不是经济机制验收的替代品。

此单元只覆盖M6审计观察子集；历史回放、多身份裁剪/缓存清理、角色工具、在线增量推送与完整工作台仍在总Plan内保留。
