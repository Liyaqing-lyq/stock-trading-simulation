# 分阶段研发机制实施 Plan

依据总体设计基线第4节、公司池研究中的研发阶段与商业化机制，作为长期投入真实行为的差异模板。当前仅批准纯核实施；不占用银行预留的schema19，不替代完整药企经营、治理或Web验收。

首切片使用一个内聚ResearchModel及必要值对象，复用唯一CashLedger和金额规则。公司可以用同一经营账户开展项目，不能为新项目复制现金。角色提出预算内阶段投入，实际资金转给有标识的有限承包方；按冻结政策形成当期费用或在研资产。正耗时未满不能完成、转固或商业化。失败证据产生真实终止与损失，未支出的下一阶段预算不得自动支付。

实验政策：三阶段，研究阶段费用化，开发与注册阶段在冻结条件满足时形成在研资产；全部完成并有实际批准事实后转可摊销资产。失败时相关在研资产一次性减值，保留已发生费用。摊销按累计应摊额减已记额计算，期末结清尾差，不能按调用次数重复费用化。该政策是模拟假设，不宣称现实会计合规。

确定性数例：公司现金1500、既有设备500，初始权益2000；承包方现金500。三阶段实际付款200/300/400，全部成功时公司现金600、既有设备500、研发形成资产700、累计费用200、权益1800；承包方现金1400，双方现金总额仍2000。若资产可使用后按60实验日摊销，30日累计350，资产净额350、权益1450。若第二阶段失败，则公司现金1000、设备500、研发资产0、累计损失费用500、权益1500；承包方现金1000。期初权益不重置。

验收顺序：

1. 纯核：阶段、现金/成本/资产闭合、失败、摊销、幂等、多个项目共享账户不足；只证明确定性机制。
2. 同世界：真实董事预算、经理权限、BEGIN/FINISH、承包方容量、证据来源与一次结果、原命令重演、旧档兼容。未来随机结果只由冻结运行规则生成并记录，恢复不能重抽；不允许模型自报成功。
3. 经营与披露：获批后的合法业务收入/履约与回款，经理/董事/外部投资者各自信息边界，周期长期投入证据来自真实项目。
4. Web及交付：阶段时间线、资金用途、费用与资产分列、失败与缺项、可追溯结果；正式组合测试、评分映射、运行记录与PR review。

本切片不新增售药库存、多产品、许可分成或独立运行器。后续完整模板的缺项保留在总Plan，不以纯核已通过冒充全部完成。
