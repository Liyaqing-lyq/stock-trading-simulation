## 权威账与边界

- 全部现金与银行准备金只存CashLedger；银行存款是银行负债和客户债权，不能再算成现金。SETTLE各持有者DUE由全部现金派生，不能另存可修改的准备金或DUE。
- 银行账簿、贷款、备查、准备、有限救助、命令/来源与现金变化形成一个候选，由唯一WorldCommit持久化。不建第二Runtime/journal/scheduler。跨行一次现金转移同时更新两行存款负债；客户正余额和贷方总账负号明确区分。
- 开局绑定OpeningRegistry的组织/账户；迁移必须实际转走原现金且origin唯一，不给银行复制资本或重复发行货币。规则档案深拷贝并冻结指纹，新激活需完整校验，新运行显式迁移；旧档不升级。
- 合法业务拒绝绑定commandId、规范请求和原回执；重放返回原结果且不回滚当前状态，补资后重试需新ID。同ID异请求冲突。不可解析协议错误可不消费ID；持久化故障整个候选不应用。此规则明确强化v8“业务拒绝不记ID”的语义。
