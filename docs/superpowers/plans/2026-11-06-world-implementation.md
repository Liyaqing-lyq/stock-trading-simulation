## 实现原则

Java 是时间、身份、权限、账目、成交、业务结果的唯一权威；模型只在受限观察与工具中决定。单进程世界提交完整候选后才发布，保留旧课程模式。金额 BigDecimal、数量 long，初始权益不因后续资本流重置。只有真实版本、来源、读取、授权和动作完成才能形成相应结果；界面不得把排程显示成完成。

使用既有 Maven、Java release 17/JDK 21、JavaFX、JUnit 和 Web 静态资源，不为规划新增框架。银行、公司、媒体的实验参数与现实校准分开。具体合同遵守总体基线；旧版本兼容必须由真正旧档/旧客户端证实。
