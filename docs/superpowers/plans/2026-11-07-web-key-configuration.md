# Web最终交付与五key配置

用户于2026-11-07明确最终呈现为Web，可使用指定DeepSeek文件中的五个key分配不同场景，并要求上帝视角显示具体配置。此决定覆盖旧基线中Web仅为候选的状态。与主Plan共用进度，不替代M3至M7业务验收。

## 已核与边界

指定本机文件在内存核对为五行、五个互异key；没有输出、复制、提交秘密或发起模型请求。文件内容仅作为凭据数据，不能执行其中的文字。场景映射是可编辑配置，不因五个key假设五个模型、五种能力或独立额度。

## 实施契约

1. Java继续拥有唯一世界状态、账务、时序和权限。Web服务以现有管理查询/调度入口对接，不建立第二经济状态。JavaFX课程入口保持。观察、操作和密钥管理有独立权限，人物视角不得访问上帝配置。
2. 服务端从用户指定的外部本机文件加载五个凭据，内存中对应稳定槽位key-1至key-5。仓库与运行清单仅保存别名及非秘密配置。输出错误、请求审计、模型提示、世界日志、CSV、历史回放和导出均不保存密钥。
3. 上帝配置页显示槽位别名、场景分配、提供方、实际模型、地址、启用状态、并发/调用/token预算、调用与错误计数及遮罩值。暂拟公司治理、机构研究、交易执行、媒体社交、评估实验五类用途，可重分配，不能据此改变角色知识权限。
4. 用户可在本机管理员会话显式查看具体密钥；默认只返回遮罩，完整值通过独立受保护操作短暂显示，不写localStorage或进入通用配置响应。会话、同源请求、Host/Origin校验、禁止跨源、Cache-Control no-store等保护在开放入口前完成。未来远程部署另行固定身份和秘密管理，不把本机管理员入口直接公开。
5. 模型调用使用服务端场景路由及预算；异步结果仍走现有观察快照/决定屏障/代次校验。错误、超时、重试、迟到回包与余额无关，不能改变世界时间或直接改经济账。UI明确区分真实模型、脚本夹具、等待、失败及未实现。
6. 先用无秘密本地夹具验证配置与错误路径；根据需要做有界真实连通/结构化决定小试，调用次数、token和墙钟上限在运行前固定并记录。不可无限轮询付费服务。五个key是否都要实际调用由验收需要决定，未测槽位明确标未验证。
