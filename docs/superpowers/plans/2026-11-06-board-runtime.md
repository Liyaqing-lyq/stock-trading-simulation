## 持久会议与权限边界

- 对外仅排程5类受信夹具：召集会议、提交材料、提出预算、投票、实施已通过预算。全部沿用writer/pause/due>now/command内容幂等/task唯一；未来到期才复核。不开放外部任意评分或passed标志，不允许直接设置预算/改钱。
- 外部召集只接受BUDGET；OPERATING_REVIEW只由期间关账的固定证据产生。开会时无预算提案不能开始表决，到截止须有REJECTED/EMPTY_PROPOSAL的明确终态，不能遗留永久冻结会议。必要时对BoardModel.closeVoting作最小RED集成修复，让已冻结但无提案的预算会议到期拒绝。
- 请求绑定明确seatId；召集仅chair，提案/材料至少属于登记且到会非回避席位，票由对应席位；这是管理夹具身份声明，不声称真实用户身份验证/任职授权。
- 召集成功与自动BOARD_OPEN待办同批；开会时冻结材料/进入预算表决，与自动BOARD_CLOSE待办同批；到期据实计算ADOPTED/REJECTED/ADJOURNED_NO_QUORUM。预算不会随ADOPTED自动生效；明确实施任务才生效，重复命令/不同命令都不重复实施。
- 自动开会RULES、普通治理动作COMPLETION；Runtime接入明确要求材料截止 < opensAt < closesAt，最少隔1模拟毫秒，避免同刻冻结/提交材料歧义；普通投票允许opensAt当刻COMPLETION、拒绝closesAt当刻。关会可RULES先拒绝截止时票。开/关时点溢出提前拒绝，不落永远无法执行待办。
- 保留反对/弃权与关联回避，预算特殊阈值按新上限合计>1000需4赞成，法定人数固定3。内部任务ID在全局已用ID找空闲，不禁止用户前缀。治理结果包含task/command/kind/meetingId/accepted/reason/模拟时点/提交位置，历史回报不可改。

## 预算与经营同一提交

- 新治理档案开局无预算；未实施有效决议时采购/投产明确拒绝BUDGET_NOT_SET，无现金/库存/承诺副作用。既有固定费用是开局合同义务，不能用预算不足漏记；回款/交付COGS不重复占预算。
- 采购按下单期间PROCUREMENT占用quantity×50，commitmentId用业务采购单唯一关联（内部前缀不同种类，不能与生产碰撞）。占用与PO/自动到货待办同批；到货实际付现金时把该原承诺从活动转为已花，付不起保存FAILED_NO_CASH并释放全部未用额。跨期间到货仍计原承诺期间，不另占新期间预算。
- 投产按当期PRODUCTION_LABOR占quantity×30，实际付款/形成WIP/预算转已花同批。预算不足必须丢弃纯候选，不能先改Model或生成child；库存/现金不足不遗留预算占用。
- 预算cap不能降到已花+活动承诺以下；通过≠执行。一次提交核对每个采购/生产承诺与Model原始ID/量/价/状态和实际cash流，未付不可标spent，失败不可留下active，到账不可双花。公司普通转账/股票申报禁令继续。
- 已关期间不得事后提案或实施预算；提案时尚未关期、实施时已经关期也须拒绝。未来期间可预先授权。恢复逐批保护既有材料、提案与选票：原记录不可改删，材料冻结后不能追加，表决结束后不能添票。

## 强制期间经营复盘

- 每次制造强制关期成功，同批捕捉该截止位置的真实公司报告/合同/应收/费用证据，建立期间唯一OPERATING_REVIEW会议、材料与下一毫秒开会任务。恢复不读取更晚状态重算旧证据；证券收盘不停止复盘。下一次关期仍必须排，不能把两个child漏一个。
- 第一期章程五席由合成场景默认到会；这是一条明确夹具假设，不假装人物自主出席。开会遵循quorum3，评分不是多数表决：可以计算客观考核材料，但预算/其他决议仍单独表决。考核完成需要清楚终态（可新增REVIEWED），不能永远留MATERIALS_FROZEN。
- 评分规则版本随档案冻结，均为实验指标：经营兑现=该期间到期合同已交付量/承诺量×100（无到期承诺则缺失）；现金偿债=AP为0时100，否则min(现金/AP,1)×100；风险=无未收AR时100，否则(1−逾期未收AR/全部未收AR)×100，其中到期时刻≤截止时刻计入逾期。使用截止时真实数量和余额，分值0–100 BigDecimal，权重总和后统一两位HALF_UP。
- 披露质量/长期投入当前无实现，永远标缺失，不给0/100、不重配权重、总分null。证据来源引用绑定已登记材料及截止提交位置。不得由LLM或外部接口传任意EvidenceMetric当世界评分。报告注明INCOMPLETE及缺项，不称完整董事会首版。此处客观评分是管理审计夹具；自动登记材料不等于人物已经阅读，不能把这些内部表直接注入后续角色上下文，实际阅读/授权仍待M4。
- 新期间复盘引用唯一历史period、material、meeting/review IDs，防碰撞/重复。场景没有借款/分红/任免/公开报告执行，明确不支持，不生成空成功回报。
