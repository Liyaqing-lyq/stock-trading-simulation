# 周期治理、考核与披露实施 Plan

依据总体设计基线第4、8、9节，接续工程世界18c。状态：纯模型第三候选已通过82项增量独审，董事材料读取接缝已有独审证据；同世界写入、披露、人物工具及恢复实施中，尚未完成Web组合。完整初版仍须其它模板、运行管理及行为实验，不能由本切片替代。

## 已确定的口径

- 实验周期固定30模拟日，一期月度复盘、三期季度考核；第1期覆盖[0,30日)，第n期覆盖[(n−1)×30日,n×30日)，在结束时点先做旧期结账/采样，再处理新期同刻普通业务。不能把结束时点的新增资本或信息混入旧期。不声称自然月或现实披露合规。规则、窗口、计划与五维权重在开局冻结，变更需新运行。
- 周期到期在同一世界帧采样截至账目及证据引用，可依据冻结章程生成会议日程，审计明确“章程自动触发”，不伪造主席本人操作，不自动出席、读取、评分或投票。
- 评分必须由真实在席、未回避、已读且能回忆准确材料版本的董事在会议窗口内完成。正工时、同一人物焦点、开始与完成两次权限检查沿现有世界机制。
- 每席一份原始评分；缺维度或合法证据记不完整，不补零、不改权重。至少三名完整有效席才形成汇总；保留各席意见，精确累加后末次统一舍入。评分本身不批准预算、任免或披露。
- 披露质量只使用截止前已成熟的记录；长期投入只使用该模板实际产生的支出、项目与计划履行证据。资料不足时总分可缺失，不用默认分冒充五维覆盖。
- 财报链为“经理准备准确草稿→至少三名有效董事分别实读批准→指定人物使用精确授权发布”。授权绑定公司、期间、草稿版本、正文摘要、用途、期限及一次消费；准备者不得批准自己的稿。
- 更正走新草稿、新读取、新审批、新版本，保留原文、原批准及原评分。错过截止保留迟报事实，后续可真实补报，不倒填原发布时间。
- 真账与公开文档分开，发布不改账；截至报告不能取现在账冒充旧期账，资本和分红继续使用唯一权威流水。第一切片实现真实报表发表与更正，主动造假披露场景仍未实现。

## 实施顺序及验收

1. **纯流程与读取接缝**：最小周期值对象、新BOARD受众；兼容已接受GROUP增量，旧接口默认无董事/群权限。验证缺席、未读、错误版本、撤权、回避、票数不足、舍入、授权错配/复用、更正和迟报。此步通过只接受纯核。
2. **同一世界接入**：状态放入schema18的公司键周期对象，包含制造与工程；复用唯一董事会、InformationModel、账户、调度与journal。人物动作走实际BEGIN/FINISH，恢复按真实原命令重演。旧≤17行为与JSON不变，不改旧董事会固定结构。
3. **真实材料与工具**：材料正文只有InformationModel一份，董事资格依据实际章程；失席停止新读取而不抹过去经历。将周期提醒、评分、审批、发布接入实际v6输入和执行工具，不把God真值或外部客户私有预算塞给人物。
4. **Web及组合验收**：复用公司、董事及信息页面，统一位置/世界时点；展示截至、实际准备/批准/发布时间、缺项、拒绝、迟报与更正链。跨公司、同刻截止、跨次启动、写入故障、自洽篡改、旧档兼容与真实HTTP/浏览器分别验证，再走正式测试、评分映射、运行记录和PR review。

纯核不得复制真账或正文，不新增独立运行器、调度器或来源图。已接受的旧制造自动复盘仅在新schema18路径切换为上述流程，不能无条件修改历史版本行为。
