# 群组与平台实施合同

依据总体基线§8–10及已接受的schema17私聊/读取规则。工程保留18、银行保留19，群平台显式新模式20；启用依据冻结模块，不以版本大于19推断必须存在银行。旧档不出现新字段。纯核第二候选已通过独审，唯一世界接入正在隔离实施，尚未接Web。

## 共同语义

- 信息正文与阅读经历仍由InformationModel唯一保存。群成员、邀请、成员时间段和帖子元数据由GroupModel保存，不建立第二正文/阅读账。群帖使用明确GROUP受众；不能用PUBLIC加页面过滤，也不能把永久DIRECT收件人假装成当前群成员。
- 目录、开读、完成与正文新访问采用同一谓词，包含人物、群、该版本发布时间与检查时刻。默认JOIN_TIME按当前加入段限制历史；显式ALL_HISTORY可提供过去版本，但仍须真实读完。更正版本按自己的发布时间判断，不改过去版本与经历。
- 退出停止新访问，已读事实与可回忆正文按既有认知规则保留；重入开启新段，不恢复旧段、不反填旧输入。未读内容不能因退群前收到过目录就永久可读。
- 所有人物加入、退出、邀请、接受/拒绝、发帖动作占正工时，沿唯一人物焦点与BEGIN屏障；系统投递不占人物焦点。发帖开始和完成查资格，已合法完成后退出不取消在途投递。
- 预置群支持OPEN和INVITE_ONLY。群主初始成员是明确的开局历史禀赋，不假称其执行过加入动作。邀请必须来自真实获准邀请人，受邀人自己接受；未知与无权不泄露对象存在性。首批不做运行期建群、踢人、历史策略修改。
- 初版邀请可无额外过期/取消功能，但受邀资格、重复待处理邀请、实际接受与成员段必须可核验。所有人退出且无可接受邀请的封闭群可保持不可加入，不自动造管理员或复活旧权限；界面明示状态。
- 同ID绑定完整语义，异体冲突。原请求与裁决保留，当前状态另列，不通过重放旧命令撤销新状态。整数溢出、倒退时间、跨主体猜ID与半完成结果均有受控结果。

## 传播与曝光

- 结构化转发只接受真实读过且仍可引用的源，规范根集合接入现有MediaModel的同源计算，不另建来源图。私有根保留内部审计，公开读者只见转述者的新陈述，不因此获得私源身份、原文访问或引用权。
- 原帖更正保留旧版本与旧经历；新版本只能通过实际渠道被呈现/读取，不自动修改所有人的信念。公开平台帖仍需真实作者、来源、时间和正工时发布。
- 可访问目录不等于已经曝光，更不等于读全文、相信或采取行动。纯核没有记录曝光时明确标未记录；完整桥仍须区分实际呈现、标题、开读、读完和后续信念/行动。不得将此切片的未实现项从总体基线删除。
- 群发布后按成员权限可见即可表示可收到，无需复制N份正文或逐成员已读账；实际阅读仍由唯一Information记录。群屏蔽偏好不默默改变成员资格。

## 实施与验收

1. 纯核：成员段、邀请、历史资格、帖子与根引用、命令绑定、JSON往返及必要不变量；独立核已合法发帖后退出仍投递、加入前历史、重入缺口、邀请授权变化和自洽篡改。
2. 信息与传播桥：GROUP统一读取、平台发布、更正与Media根消费；旧受众与旧版本输入保持，人物查询不含管理员私根。
3. 唯一世界：真实BEGIN/FINISH/投递、跨公司治理/私聊/阅读等共享焦点、逐帧重放与写故障、同命令幂等、旧档门禁；输入和工具实际驱动，不靠直接纯核调用冒称端到端。
4. Web：God审计与本人视角、群邀请/加入/退出、版本/阅读/转发状态、历史与导出同权限；实际HTTP和浏览器验收。

定向反例至少包含三人群、一名外人猜ID、读到一半退群、已读退群后遗忘、两次加入间隔、邀请人与受邀人分别失权、同源转发链和私源转述。不能以纯核自测通过代替跨模块传播、恢复和Web证据。最终同步评分表、正式运行记录及PR人工review要求。
