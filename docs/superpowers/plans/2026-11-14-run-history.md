# 历史回看、检查点与独立分支实施 Plan

依据总体设计基线第10–12节。活跃运行的历史回看与独立分支分开验收；不能把已有完整快照等同于两者都已完成。当前只授权后述A切片实施，B仍需完成设计核验。

## A：活跃已验运行的只读历史与检查点

从唯一运行已经恢复并逐帧语义核验的确认批次取历史，按提交位置固定边界。不能只按毫秒筛选而引入同刻后续事实，也不能先改当前状态、渲染后再改回来。列表分页，所有历史面板共用同一运行、位置与截止位置。任何只能读取实时状态的条目明确保留缺项。

God页面提供历史总览、账户、证券、待办、人物任职、资料索引及已有经营/群组事实；没有业务写按钮。普通人物不获得God历史权限，退出、换身份、离页及切换位置后的迟到响应不能回填。

检查点导出完整确认边界信封：产物版本、运行/位置/时间、manifest及开局配置、原始状态和来源摘要。此切片只是导出与对照核验，不能宣称已可独立恢复或开分支。核验必须对照已验运行的真实原提交；自洽修改状态并重新计算摘要仍须拒绝。摘要口径必须明确，不能把重编码内容的摘要称为原日志字节摘要。

验收：历史p与运行恰停p的事实一致；同刻多提交不穿越；固定截止后新写入不改变旧视图；查询/导出不修改日志、时钟、曝光、阅读、预算或调用模型；身份拒绝、非法位置、缺模块、检查点篡改与正例；网页真实入口及迟到回包。

不以`new WorldJournal(...)`作为只读浏览入口：其构造会取得写锁并清理不完整尾部，真实探针已经确认。本切片不接任意服务器文件路径、跨文件浏览或检查点导入。旧档语义与状态版本不变。

## B：独立分支，设计尚未验收

必须从已验证父边界确定性派生子状态，再验证新档；不能把新首帧自身设为期望值后称其有效。新运行标识、父运行/位置/摘要、完整资产义务与待办、去重、模型尝试/恢复代次、旧历史引用及表现基准都需明确转换或保留规则。

已记录决定不得重问，旧进程/分支回包不得写入新分支；未决工作若暂不支持切分，须明确拒绝且保留原状态。God查看秘密后的人工接管须标记分支或受干预实验。父日志保持不变，分支财产不得回流合并进父运行；新决定可能不同，不冒称原实验回放。

现阶段“只改三处runId”的设计不足以证明上述条件，不能接入。后续先补可执行转换对照，再实施分支与Web管理。
