# M4i.2a 采访预约运行桥与 Web：实施合同

依据总体基线及媒体社交细化§6–9，接已验收M4h.2和待最终独审的M4i.1。先闭合双方预约的真实时间、工时、权限、恢复和网页链路；逐轮正文/真实阅读为M4i.2b，私有采访证据/匿名谱系为M4i.2c。本步不宣称完整采访或匿名功能完成。

## 权威状态和兼容

- schema14显式实验档，旧1–13保持原有行为、JSON、决定输入和恢复。不开自动迁移。InterviewRun.Config冻结每媒体Policy、动作时长和有出处的联系入口；每机构一份InterviewModel.State，均在唯一世界journal内。
- 纯核fromJson只验证内部一致性，不能作为可信恢复入口。每帧恢复必须从开局OpeningRegistry与InterviewRun.Config重建合法人物集合/机构/Policy，再按真实命令重放并逐字段比较；独审E13“向persons追加未登记人物”必须在运行桥成为拒绝反例，连同修改Policy、联系入口一起验证。
- 保留纯核单机构Policy。允许增加只读实际占用投影供适配器复用；其他机构真实预约/会话、pending和在途阅读共同派生Context.busy，逐次用完即弃，不持久第二占用表。同帧接受/开始按真实确认顺序校验，不能分别基于同一旧帧双约成功。
- 不改MediaRun.Config旧public record形状。采访时长在InterviewRun.Config，支出仍进唯一MediaRun.Budget及Work；新方法可显式接收采访参数。新schema才启用采访工作种类，旧13不得受新种类或字段污染。作者先给api.md与预算一致性路径，Root核对后继续。
- 双方整个同步区间都不可与其他占注意力动作重叠；组织工时按记者实际占用计费，同一记者的会话不得兼收发言工时造成重复记账。普通受访者无媒体任职/工时账，不伪造其机构；其时间占用仍是真约束。开始前预留最大全程、提前结束释放未用余量，结束/拒绝/取消不得因预算不足被困住。账本须能按工作事实独立复算，不另记余额。

## 接触与双方决定

- 联系入口不是世界人物目录。最小配置为明确目标人物、渠道、可见联系说明和锚定资料docId/version；只有本人实际读到且现有角色信息/回忆机制允许提取的入口可进入候选。目录仅有publisher不自动授予联系渠道。已发生直接往来可提供回联系依据；结构化引介在后续消息层实施，不先造完整社交关系框架。
- 邀请、接受/拒绝、取消、结束均从真实WorldRoleSession/DecisionRun动作进入，有正模拟耗时、稳定人物命令与任务标识。使用纯核requestId helper，不允许模型指定别人命名空间。对象自主接受/拒绝；发起者不得代答。
- 接受已确认的未来时间后，系统到点只执行双方已同意预约的开始门；复核权限、所有实际占用和预算后才ACTIVE。冲突/撤职不能假造谈话。错过时点、邀请到期和正常结束均产生确定终态，系统门任务由真实先前状态派生，不能伪造TASK_SCHEDULED事件冒充用户授权。
- 邀请/接受/开始/继续新操作检查当前记者授权；决定触发还须验证原观察帧授权。拒绝/取消/结束允许无现职释放资源。历史已发生内容不拿当前权限重判。未知和无权请求/会话对人物接口一致。
- 预约通知属于协调元数据，不能让它自动生成采访正文、阅读、信念、关系经历或知识。M4i.2b再用DIRECT资料投递真实逐轮内容；收到不等于读到，不自动替对方排阅读。

## 运行与展示

- 新排任务严格绑定本批首次原命令、人物、clientCommandId/clientTaskId、完整内容、回报、观察位置和到期时间；沿用媒体C9已修的规则。恢复从前帧和真实任务重算完整采访/预算/派生门任务，拒绝仅改snapshot且重算摘要、克隆pending连带伪造排程事件、历史决定重放和删门任务。
- 角色工具仅在schema14加入，双方都能回应/取消/结束自己的预约，只有记者能发起。普通投资者不能借此取得组织写稿权限。模型请求仍走已有有界提供方/预算设施；默认场景关闭，不用真实Key做本步回归。
- Web新增预约审计：上帝视角看实际双方、机构、窗/约定/实际区间、状态、拒绝原因和真实工时；人物页只本人参与的协调事实、可达入口与可用动作。切身份/离页清空，HTTP同权限，不靠前端隐藏。明确“预约协调；逐轮访谈尚未接入”。不显示未产生的正文或模拟成果。

## 验收

正常链：公开模拟联系入口实际发布和阅读→记者邀请→对方自主接受→到点开始→提前结束→余量可继续采编；另有拒绝、取消、无人回应过期、未赴约/开始失败。覆盖两媒体争同一受访者、同刻准入顺序、前后紧邻、0时点/溢出、离任、真实阅读冲突、所有资源占满仍可结束、早结束预算释放、普通受访者无需机构任职、身份隔离与未知ID。

保存独立JVM恢复、写入故障、pending/命令/事件/预算/状态篡改矩阵和真实DecisionRun工具链证据。旧13冻结客户端不重编：复制old13-original由新类续媒体帧，再以旧类读取；旧12沿用既有夹具。不能让旧类读取新14档，不能把其预期拒绝称兼容失败。正式verify含GUI、JavaDoc、评分映射、真实运行记录和AI草稿PR仍为完成门槛。

真实Hermes按隔离目录承担实现、定向回归和独立复核；Root保留设计裁定、主树接入和最终证据验收。当前仅合同，尚未授权作者开始本桥；待纯核最终接收后明确文件范围。管理员可审计私有记录但后续人物投影只能看到本人获权且实际读过的材料；本步不增具名/匿名身份披露Policy，也不把编辑知悉真实身份设成全部匿名稿的默认门槛。
