## 版本、资源与接口澄清

- 纯核基准为`logs/implementation-20261106-continued/media-editorial-candidate-3`。每次submit必须从同一世界cut的MediaRun组合传入其他媒体State；不得遗漏跨媒体谱系、信任模型提供的根、或复制正文到媒体状态。
- 将媒体组织的Policy、总工时预算与动作时长随新开局冻结。写稿、审阅、发布按Policy时长真实预留；提出选题/开启更正也有显式正动作时长，是否计组织工时必须在api.md统一声明并验证。取消是独立有时点的控制动作，不得为取消再要求足够剩余写稿预算。无日历重置，明确总预算实验口径。
- 原`InformationModel.publish`资料在完成时点生成，但新角色不得在同一时点收到并使用新消息；阅读排程必须晚于当前cut，受信适配器保证下一毫秒开始。不能先把未来资料加入当前可见目录；需要DELIVERY子任务时必须完整持久、重算和恢复。

- 媒体角色权限清单在新档案按组织范围显式加入三动作；schema1–12仍只有原七动作。旧`requireLegacyRole`门仅对媒体新档案开放。保留旧DTO构造、null省略和旧inputText逐字结果，不借此放宽其他模块。
