# B2c 真实模型 Web 闭环实施准备

依赖：B2b最终验收与草稿PR实际CI；Web只读详情候选另行验收。此文件为Root接线契约草案，尚未授予生产写权，不记完成。用户明确最终Web与五key场景配置，授权Codex判断真实测试；现有单次51token探针不得重跑。

## 必须交付的闭环

管理员显式开始一次有界角色轮次 → 服务端从任职生成四岗真实观察 → 冻结当前启用场景/slot/model/预算 → 先WorldJournal确认dispatch → 有界HTTP工作线程一次请求 → 不可变完成候选 → 唯一writer记录技术或业务结果 → 管理页展示观察材料、配置与真实回报 → 模拟推进完成合法业务动作。浏览器无刷新也能应用回执。保存配置、启动服务器、重启恢复均不得自动请求模型。

只读页数据使用同页确认截止；模型来源不是全知页。research用于研究岗，trading用于组合/风控/执行，治理/媒体/评估仍配置但无已连接执行器时明确未接入。真实费用未知null；模拟资金不支付真实API账单。

## 运行与安全约束

- 新live档案新runId/目录，与旧schema9 Web档案并存，不迁移或覆盖旧日志。旧课程和scripted入口保持。
- 世界纯核不依赖HTTP类。worker仅收到不可变Call、冻结Route及服务端凭据Supplier，不能读取世界、管理视图或调用状态转换。
- 固定官方端点；测试只包内回环构造与dummy五key；不新增用户任意URL入口。KeySlots原文件外置；logs/journal/CSV/PR/错误不含密钥；完整Key仍仅本机管理员显式查看。
- 有界executor与完成存储，拒绝排队不能丢已经持久授权的attempt；按run+scene并发和预算许可先决定有无worker位置，再持久dispatch，最多一次HTTP。每个attempt的本地身份为完整record，不靠带分隔符字符串拼接。
- 保留既有scene revision/冻计划：关闭场景只阻止新调用，不改变已发请求slot/model/output。晚来的预算更新不退还消费。所有UI配额须明确累积口径及已耗/预留/剩余。
- 停止轮次禁止新请求，接收并结算已在途；暂停不推进/不应用结果，候选有界保留；关闭释放自身线程/端口；网络取消不能宣称供应方未收费。重启保守结算旧代次，只有新的显式开始才发送新attempt。

## 完成时点与技术失败（先核准后实现）

1. 第一次宿主收到完成的时点由宿主采集，重投/队列满/暂停不能重取。只读HTTP队列满不会丢模型结果。不允许调用者提供任意到达时间伪造及时回执。
2. 登记完成与超时选择使用同一个小同步点，且不在其内做journal/HTTP/世界计算。正常在期限内登记的结果即使writer延迟/暂停也不超时；期限后登记不能借先drain后expire获得业务效果。定义为宿主登记时点，不冒称物理网络末字节到达时点。
3. 每个已授权attempt只有一个有界完成槽（或等价机制），元数据独立于世界状态；重复相同结果不刷新时钟，冲突有固定回报。超时与回执竞态只能有一个首次结算，晚回执仅审计，不再下单。
4. 原scripted行为和旧journal语义保持。live直投入口与异步入口须共享同一截止规则，不能留公开旁路；测试原5ms合法审计夹具若需要延长超时，仅改正合法时间窗口并保留真实超时步骤，不删除断言。
5. HTTP COMPLETE与正文的工具合法性分开。LENGTH/FILTERED/EMPTY/TOOL_CALLS及传输异常必须是技术结果，不能变观望。提供方已给usage就保存真实声明；没有usage保守按预留且费用未知。不得为了用submitReply伪造role.wait正文。
6. 优先复用DecisionModel.rejectReply作为有提供方响应但不可用正文的技术失败（规范化空正文须明确说明，保留真实声明及来源）；如需要新类型或扩展纯核，先列字段/旧档兼容/逐批恢复契约，不能无通知扩成平行账本。
7. 每种新领域事件均有原command来源与逐帧重建；首次完成/迟到审计/超时/拒绝批次都保持经济和时间不变，业务效果只由原计划完成事件产生。派发许可、网络结果、工具解析、业务执行是四个不同状态。
