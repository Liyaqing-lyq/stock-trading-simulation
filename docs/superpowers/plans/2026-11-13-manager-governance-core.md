# M5 治理前置：公司经理任免纯核合同

目的：董事会能够对公司经理任免形成可验证授权；授权生成、实际任职生效、经营动作三者分开。基于既有五席董事会，不凭一句模型文字更换经理。工程运行桥及多公司董事会另接，不把本阶段称治理闭环完成。

## 冻结规则

- 任免沿用原章程法定人数3、普通事项3票；关联回避不降低分母。APPOINT与REVOKE同门槛；不要求全5席到会。公司经理是独立Role.COMPANY_MANAGER，不借PORTFOLIO_MANAGER。
- 请求绑定公司、人物、任职ID、任命/撤销、精确生效时点及任职期限。任命期限为[start,end)，授权不得在生效时点之后才产生，不能追溯授权。撤销必须绑定旧任职完整身份与有效撤销时点，不允许把REVOKE请求当成新任命或同ID不同对象。纯核不认识真实任职表，授权只是待执行许可；实际记录存在/未撤销/生效区间由桥在排程和到期验证。
- 公司必须等于章程公司；候选人或被撤销人在本公司占席时该席自动属于关联席，不能靠漏填relatedSeatIds规避。关联席不到会不要求强行到会；到会则回避，不投票。同一公司同岗位的活动任命提案冲突不限于同一人；撤销旧任职不是再次使用ID任命，不能被粗糙唯一性检查拒绝合法撤销。
- 复用现有会议召集、材料截止、到会、选票、结束规则，不另造第二套投票。完成实施生成授权，其引用绑定完整请求、章程、会议、材料、逐席票和签发时点。用真实会议状态验证，hash本身不是外部授权凭证。非法或被篡改的IMPLEMENTED/ADOPTED状态必须拒绝，不可自己重算digest就伪造通过。
- 重复实施按现有董事会风格拒绝或返回同授权，不得改变先前结果。授权表不直接改RoleAccess。真正世界命令幂等/单焦点/任务写入留给桥。
- RoleAccess新增独立经理权限（读本公司账/请求经营/供应商付款/申请减值核销），不授予客户验收、直接拉款、豁免、修改现金或世界真值。沿用既有同组织同岗位不能重叠任职、同人同组织不兼不同岗；可跨公司任职但未来桥共享人物工时。
- 所有现有schema≤17均不得因此取得公司经理能力。允许最小WorldRuntime requireLegacyRole拒新角色及任免议题排程/恢复门禁修改；若Board Topic新值能从既有通用接口进入旧档，必须拒绝。不增加新schema/config/公司账/模型工具/Web；未来18治理工程桥才能显式启用。旧序列化构造保留、无新内容的旧快照不能悄悄多写null字段改变旧内容摘要。

## 验收

真实公共入口：3票通过、2票拒绝、回避后不足3延期；关联席身份自动识别、未到会不误拒；跨公司/基金岗位/未授权召集/时间倒退或晚授权拒绝；任命与撤销完整绑定、同任职被换人/期限/动作不能验证；同机构不同候选人重叠提案；重复实施无额外授权；撤销不删历史。独立JSON篡改议题、选票、关联席、签发时间、request、状态（包括自洽digest组合）拒绝。原董事会/分红/角色测试必要回归，旧manifest开局/排程/恢复不得接新角色或新议题。纯核不等于实际任免闭环。
