# M4i.2c 匿名私有证据与身份共享实施合同

依据媒体社交运行细化及已裁定minimality-check，schema16启用；旧1–15保持行为/JSON。b运行桥尚在实施，当前仅授权隔离纯核，不改Runtime/Web。

- 复用MediaModel.Story.evidence/roots保存全部真实证据与根，复用按公开文档版本的Lineage；不新建第二根账本，不造PUBLIC中间资料。
- 作者提交私证必须本人实际读完、该版本可引用且可回忆；公开转述者仅须真读公开文章，其继承私根不授予访问。根按真实publisher去重，不信自报来源数量。纯私证、混合、跨社转述与更正旧版本均成立。
- AliasBinding(story,revision,root,label)只做本稿版本展示，root必须来自本版实际证据；公开只给标签不泄露root/doc/publisher。同源不同标签不增加组数；旧版标签与谱系保留。
- EvidenceState只存aliases/shares，MediaModel.State既有形状不改。新submit显式接旧EvidenceState与回忆配置，返回完整新状态，不丢已有别名/共享。
- 身份共享由真实记者显式命令触发，必须本人实际读过根、有合法任职且仍可回忆。ShareRequest标明根与真实接收者；程序从真实根publisher派生身份说明，通过既有InformationModel发布通用标题DIRECT，publisher为分享者；同一纯计算结果返回信息状态及最小IdentityShare绑定，不把任意无关DIRECT事后登记成身份资料。身份、正文、时间/阅读不复制进第二账本。共享原子，失败不部分写。
- 同一命令同一内容幂等；不同命令再次共享允许（对方可能遗忘/版本已变），不能仅(root,recipient)永久去重。shareId由真实人物命令命名空间派生，不许跨人碰撞或探测。
- 编辑须真实读完共享版本且当前能回忆才知道。匿名稿不强制共享；继任者不自动继承。硬性读权限不等于正文审查：已知身份可以被言语说出，不承诺自动检测或永不泄露。
- 新核心公共API中文JavaDoc，正常/拒绝/幂等/碰撞/版本/权限/时间边界均有意义测试。新submit保留旧方法/签名/结果；可用最小共享private helper，不复制整个旧采编实现。
- 后续桥必须从真实命令、观察与完成帧重算，不以最终JSON自洽替代真实性；配置冻结、旧15真客户端、Web权限和独立验收后才能称阶段完成。

接口准备api-v2仅为线索；以上裁定覆盖其遗漏（submit需EvidenceState、共享应真实生成、不得永久按根+接收者幂等）。不预先实现普通私聊、群组、关系网络。

二次共享补充：人物可以在真实读完且仍记得身份共享材料后再次共享；身份说明必须沿既有共享绑定解析到原始来源，不能把中间人写成原始来源。绑定保留本次实际读到的来源锚以验证命令与经历，原始根从绑定链派生，不再复制一份。此过程不授予任何人读取原私证的权限。
