# M5 董事参与登记前置合同

用于后续schema18异步董事会；只补既有BoardModel的参与登记，不能把纯核当真实人物到会或治理闭环。董事会采用异步材料阅读与表决窗口：登记表示本人完成参与确认，不表示整场连续在场；读取与投票各有正耗时，任何两个动作仍不能因属于同一会议而同时占用同一人物。

## 最小纯核

新增参加方法（名称可沿attend，中文Javadoc明确异步参与）：接收state/now/meetingId/seatId及自主回避。既有convene/JSON/record字段不变；仅CONVENED且createdAt<=now<opensAt允许登记既有章程席位。未知会议/席位、过去/截止以后、材料冻结/表决后拒绝且原状态不变；重复同一登记不得重复席位或清除先前回避。

任免对象对应席位、任免或分红提案relatedSeatIds中的席位即使晚加入也自动回避；自主不回避不得覆盖强制回避。加入名单保留全部提案、材料与其他字段，不可改变已存在授权或票。不得补记已经过去的到会；世界桥后继以真实人物、任务、报告逐帧重演绑定，纯核seatId不是外部身份凭证。

顺序相反时沿用旧提案规则：本人已登记但尚未回避，随后提案才识别出关联关系，提案必须拒绝且不写入；本人在会务窗口内补充自主回避后可重新提交。不能接受未回避提案，也不要求此新登记方法改变旧提案的拒绝语义。此前复核任务所说“原逻辑仍自动回避”是Root对旧行为的错误假设；实际旧逻辑是识别关联并拒绝。两种顺序各自验证可完成的合法链，不能把安全拒绝本身当成权限漏洞。

会务窗口内先空名单召集，再真实参与确认；opensAt后名单冻结，按既有法定人数/普通事项3票/关联回避规则表决。投票前材料实读、实际任免及公司预算执行属于18桥，纯核不新建阅读账。旧入口仍支持可信场景给定的到会名单；旧档不升级。

## 工程预算裁定

复用现有PRODUCTION_LABOR预算约束工程人工，PROCUREMENT约束分包服务；预算按公司独立，不新增行业专属枚举。开工同批预留并支用人工和分包两笔；任一额度不足不付钱、不记应付、不建工单。已发生的应付支付不再次支用预算，也不因后续预算降低拒绝偿债；已支用额度不因终止回滚。经营模板可映射这两个现有类别，但不得扩成隐藏权限。桥实施时验证这些规则，本纯核阶段不声称已接。

## 验收与边界

真实纯核序列：空名单→三人登记→真实3票通过；两人不足；同一人重复/自主回避不撤销；任免对象晚到与related晚到自动回避；不同会议隔离；过去、未知、截止同刻、表决后拒绝；原经理任免/分红/预算必要回归；JSON往返后结果与强制回避不漂移。只新增方法/私有帮助方法/测试，保持全部既有公开API/序列化。作者隔离目录governance-attendance-author，独审接受后随18桥接主树，不能混入尚未完成的schema17交付。
