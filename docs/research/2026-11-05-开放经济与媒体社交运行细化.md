# 开放经济、媒体与 Agent 社交：运行设计细化

> 2026-11-05 统一入口：本文保留专题依据和设计演进；跨模块规则、冲突处置及实施门槛以[总体设计基线](../design/总体设计基线.md)为准。本文中的草案、原型和计划不代表功能已实现。

日期：2026-11-05。状态：根据用户最新纠正形成的设计规格草案；没有运行世界、修改 Java 或调用真实电话。本文将此前研究落到机制、状态、行动与验收，不重新讨论已经确定的信任、遗忘和习惯变化方向。

## 1. 本轮采用的决定

1. 十家公司是重点观察的上市主体，不是完整国民经济，不要求彼此形成供应链或现金循环。
2. 允许外部客户、供应商、竞争者、居民、金融机构、海外部门和外部条件；真实关系没有证据时，不强行写成它们之间的合同。
3. 公司机制从真实公司公开披露与经营实践学习；公开材料不等于真实公司的完整内部实时账。虚构世界仍可偏离真实历史，原型映射不进入角色上下文。
4. 媒体有独立 Agent、选题、信息搜集、核实、编辑和发布行为；不同类型不能只靠换名字和语气区分。
5. 评论属于人物自己的社交身份；同一人物可有评论、私聊、模拟电话、模拟线下调研。社交账户和证券资金账在底层分离，界面可以同属一个人物主页。
6. 评论允许口语、玩笑、自嘲、反讽和争论，不要求所有人像研究报告；表达仍围绕当时的股票、事件和个人处境。
7. 继承遗忘、偏信与习惯变化，以及四个机构岗位独立决策。以下补全行动机制，参数是可检验的初始提议，不宣称已校准现实。

## 2. 世界开放，账目可追踪

### 2.1 三层世界

| 层 | 模拟什么 | 建模程度 |
| --- | --- | --- |
| 焦点主体 | 十家虚构上市公司、银行、重点机构与人物、媒体 | 独立资源、账目、决策、合同和信息；需要语言判断的岗位运行 Agent |
| 外部部门 | 国内／海外客户群、原材料供应商、经销商、竞争者、家庭与外部金融部门 | 按行业、地区、期限等聚合；有需求、容量、付款和违约规则，不强制每个成员运行 LLM |
| 外部条件 | 利率环境、汇率、海外需求、原材料供给、水文、技术替代、政策事件 | 有来源和版本的条件路径或情景过程；先改变经营约束，不直接指定股票涨跌 |

开放边界采用“焦点主体完整记账 + 跨边界流量与对手科目可查”。不承诺建立整个外部国家的完整资产负债表；每条边界支付仍必须知道方向、金额、用途、对手部门与形成原因。对手内部未建模部分标为聚合或外生，不虚构已经核算的细节。

贷款创造存款、银行间结算和还本等金融事件另有双边会计约束，不能把“开放经济”用作随机充值理由。宏观需求改善本身也不是一笔入金。

### 2.2 十类公司的外部连接

以下是虚构世界的经营模板，不是对十家真实公司的交易对手认定；依据仍使用此前公司池研究中的年报。

| 焦点类型 | 主要外部对象／条件 | 内部需要保存的状态 | 影响进入公司的路径 |
| --- | --- | --- | --- |
| 高速互联制造 | 海外客户群、芯片与器件供应商、技术路线 | 认证、订单、关键物料、良率、产能、出货和回款 | 需求／认证 → 订单 → 采购与生产 → 交付 → 收款 |
| 品牌消费 | 经销商、直营客户、居民消费和渠道竞争 | 陈化库存、渠道库存、售价、退货与回款 | 终端购买与渠道进货分别变化，不把经销进货当全部终端消费 |
| 动力与储能 | 汽车／储能客户、原料与替代技术 | 产品组合、产能利用、合同价格、材料成本 | 产品销量与售价、原料成本和技术投入共同变化 |
| 工程履约 | 房地产、公共设施及商业客户群 | 在手合同、履约进度、验收、应收与逾期 | 签约、收入确认、开票与现金到账分别发生 |
| 银行 | 储户、借款群体、结算对手、融资市场 | 贷款、存款、期限、减值、资本与流动性 | 重定价、信用迁移、提款与结算；直接贷款只是组合一部分 |
| 能源 | 煤电客户、运输需求与能源价格 | 产量、运输能力、内部供给、库存、售价和成本 | 一体化环节按真实物量和成本衔接 |
| 数字商业化 | 企业客户、广告与数字化预算、竞争方案 | 试点、转化率、合同、交付、研发与回款 | 技术展示不能自动变成收费合同 |
| 材料 | 工业客户、消费用途、替代材料与产能 | 产品结构、成本、价格、库存、新用途验证 | 成熟品周期与新产品验证分别演进 |
| 水电 | 水文、电网需求、结算电价和债务 | 来水、库容、检修、发电量、售电与偿债 | 水量和机组约束先决定可供电量 |
| 医药 | 研发合作方、支付方、医生患者需求、审批环境 | 研发阶段、证据、预算、授权、销售和里程碑条件 | 阶段证据、批准、收入、附条件付款不能混同 |

焦点企业间默认没有商业合同。只有设定业务上合理、双方有资源且实际获批的合同，才建立直接边。即便没有彼此交易，也可以因共同海外需求、融资条件或投资者资金流而联动；共同暴露不是双方交易。

直接联系状态为：候选交易 → 双方协商 → 合同生效 → 履约／交付 → 应收应付 → 支付或争议／违约 → 结清。一次会谈不能自动跳到签约，一次订单不能自动跳到收款。

### 2.3 外部条件不能成为万能剧情按钮

每个条件定义作用对象、单位、持续时间、进入哪个数量／价格／成本方程、调整滞后及相关来源。例如海外需求下降影响客户订单倾向；企业仍可调价、换客户或削减投资，结果不必相同。

外部客户群应有购买规模、供应商选择、付款能力和交期约束；供应商有产能、库存、报价和交付约束；外部储户与资金方有到期和提现／申赎行为。可用规则处理大量同类成员，重点联系人再具体化为人物。不能在访谈时临时创造一个知道所有秘密的“业内人士”。

## 3. 如何从真实披露学习公司

### 3.1 三个时间与三类结论

现实资料记录报告期／实际事件时间、公开时间、系统取得时间。模拟资料另有虚构发生、发布与接收时间，二者不能直接混用。

| 材料层 | 例子 | 用途与禁止事项 |
| --- | --- | --- |
| 已公开事实或公司表述 | 定期报告、公告、投关问答、公开合同条款 | 保存主体、日期、版本、原文定位；“公司这样表示”不自动等于独立验证的真相 |
| 由公开资料约束的估计 | 未披露订单结构、客户集中度范围、隐含周期 | 保存假设与区间；不能标成真实内部事实 |
| 虚构运行状态 | 某虚构客户订单、设备到货、管理层选择 | 由场景初始状态和后续动作生成；不伪称是现实公司当下状况 |

现实公开资料库可以持续更新；每次更新先形成候选变更和影响清单。运行实例绑定资料与参数版本。普通更新服务不直接改写运行中的历史合同、余额或秘密。

这里将用户所说的“实时学习”落实为两件事：公司在模拟时间内持续经营；研究资料可以随真实披露更新。默认对运行使用版本锁定。若研究实时外部冲击，可另启“受控导入”模式：去掉原型标识，映射为有单位与作用范围的外部条件，在预定模拟时点形成显式事件并记录来源；不把新的现实财报硬覆盖虚构公司的经营结果。

### 3.2 每家公司维护一份机制说明

至少包含：业务环节、收入确认与收款条件、关键物量／产能、成本、投资与债务、可选管理动作、完成时间和失败条件、董事会指标、定期披露日历、临时披露触发、投关回答范围，以及所有参数的来源／估计标签。

每个经营动作按“所需资源 → 执行时间 → 阶段结果 → 可观察证据 → 披露安排”写清。例如扩产需要预算和设备订单，先支付或承担应付款，再建设安装验证，达到条件才增加产能；新闻稿不能直接增加产能。

### 3.3 真实投关记录给我们的具体启发

[中际旭创 2026-05-15 投资者网上集体接待记录](https://static.cninfo.com.cn/finalpage/2026-05-15/1225311210.PDF)中，回答会纠正提问者的业绩指引前提、解释供给保障方式，也会把具体业绩引回定期报告。可据此设计“纠正前提、解释机制、引用已披露材料、保留不确定性、拒绝给未披露数字”等动作；不照搬真实产品名和未来剧情。

同公司的[2026-01-31 电话会议记录，次日披露](https://static.cninfo.com.cn/finalpage/2026-02-01/1224960917.PDF)提供了订单、供给、产能和产品阶段的具体交流实践。电话发生与纪要公开是两个时点：参与者先收到谈话，其他角色之后才能读到公开纪要。该差异要真实保留，不能把全部电话永久视为私人或立即广播全文。

投关渠道的制度参考采用明确版本：[证监会 2022 年指引](https://www.csrc.gov.cn/csrc/c101954/c2334702/content.shtml)，以及[2025 年信息披露管理办法发布文本](https://www.csrc.gov.cn/csrc/c101953/c7547359/content.shtml)。已核读前者电话、来访与平等沟通条款；不是声称完整审查截至研究日所有后续修订。

## 4. 银行与机构规则补齐

### 4.1 银行沿既有会计模型增加执行条件

沿用《虚拟银行约束与详情工作区设计》的存款创造、结算、损失和救助机制。每笔业务依次通过：

1. **客户调查**：借款用途、偿债来源、已知债务、关联集团、抵押及资料时效；授信岗位只能看到其当时获知的资料。
2. **额度审批**：检查放款后资本、总敞口、集团与行业集中度、未提款承诺、期限结构；记录拒绝或附条件批准。
3. **提款复核**：确认合同、用途条件、授权与版本，预留需要的支付资源；批准额度本身不创造存款。
4. **入账与结算**：本金同时形成银行贷款／存款和企业存款／借款；外部支付另校验结算资金，不允许半边成功。
5. **贷后处理**：现金流变化、到期、逾期、风险迁移、减值、重组、回收和核销均有时间与原因；续贷不清空历史。
6. **治理与处置**：风险超限触发限额收紧、分红约束、融资或增资计划、董事会复核；援助不成功时允许进入处置。

银行可复用“调查／业务决策／风险／操作执行”的职责分离，但不把基金四个岗位原样改名充当所有银行组织。银行的经营负责人和董事会负责资产负债与风险偏好；操作岗不能自行批准授信，客户经理不能自己改准备金或资产风险分类。

首轮只需少量有真实业务动机的直接借款人，其余用可复算的背景组合。直接贷款是场景可选关系，不能为展示传染而强制十家公司都向焦点银行借钱。

本轮补核的中国银行规则如下。使用明确基础版本，不声称已穷尽全部后续通知和个别机构附加要求：

| 规则来源 | 本轮读取 | 如何落到配置和计算 |
| --- | --- | --- |
| [商业银行资本管理办法，2023 年第 4 号令，2024-01-01 施行](https://www.ssf.gov.cn/portal/rootfiles/2024/01/12/1706726551172571-1706726551184020.pdf) | 第 2、5–7、25–35 条 | 机构分档、不同资本层级、风险资产与杠杆敞口分别计算；基本要求和适用附加要求分开，先充分计提减值 |
| [商业银行流动性风险管理办法，2018 年版政府全文](https://www.hengqin.gov.cn/lab/flfg/bmgz/content/post_3644587.html) | 第 2、7–11、27–29、35–43、72–75 条 | 先判定适用指标，再计算日间支付、到期缺口、压力流出和期限匹配；不混用不同规模机构或历史过渡期门槛 |
| [商业银行大额风险暴露管理办法，2018 年版政府全文](https://jrj.sh.gov.cn/YWTBZCCX166/20180507/0031-151724.html) | 第 2–9、13–24、26–37 条及附件 1 | 单户贷款、风险暴露、关联集团和表外承诺分别处理；不同口径使用对应资本基数，不统一除以一个数字 |

银行场景在启动前必须声明规则版本、规模分档、系统重要性等适用条件，以及采用真实基础规则还是明确简化的实验规则。缺少适用条件不能静默补成“无附加约束”；阈值与解释同版本保存。未来确需复刻完整现实制度时，再完成全部补充规则核验。

[招商银行 2025 年度业绩发布会问答](https://s3gw.cmbimg.com/lb5001-cmbweb-prd-1255000097/cmbir/20260331/a1620cd2-b567-4db0-ba02-9ee174aa4693.pdf)（会议 2026-03-30）Q7–Q9、Q11 展示客户／产品、资本消耗、分红和预期信用损失的管理取舍。结合此前年报，本模拟将存款按公司／居民、活期／定期分组，给贷款设置行业和期限结构、重定价日以及风险迁移。管理层可以改变新业务结构、融资、定价和分红建议，但不能为了获得批准自行改写已发生损失。

### 4.2 基金机构的交接、冲突和考核

| 岗位 | 输入与独立输出 | 不能代做的决定 | 考核依据 |
| --- | --- | --- | --- |
| 研究员 | 研究问题、证据及相反材料 → 假设、概率、估值范围、失效条件和更新报告 | 不能直接改变持仓或把机构资金拿去调研之外的用途 | 证据准确与可追溯、预测校准、更新及时性、有效覆盖；不用事后股价单独判定研究质量 |
| 基金经理 | 研究、组合、现金义务与委托 → 目标配置、期限、资金来源和优先级 | 不能覆盖硬限制或把“想买”当成成交 | 风险调整后的组合表现、基准、回撤、现金义务、授权一致性；控制申赎影响 |
| 风控 | 同时看现有持仓、挂单、待执行任务、合同与资金义务 → 批准、限额、暂停或拒绝，附证据和期限 | 不能替经理随意选股，也不能用“谨慎”永久封禁所有风险 | 风险覆盖、漏报、无效阻断、解除及时性、是否正确处理共同敞口 |
| 执行交易员 | 获批母任务及实时行情 → 子单、撤单、节奏、无法完成的反馈 | 不能更改投资方向、突破总量价格期限或转移账户资金 | 完成度、含未成交机会成本的执行偏差、越权和异常响应；不是只比成交均价 |

共享账户有唯一权威目标版本，岗位可以保留自己的建议版本。默认流程：研究建议 → 经理提交组合意图 → 风控校验 → 经理确认获批任务 → 执行。委托内预先批准的日常调仓可使用有效授权，避免所有小单都召开会议。

冲突处理采用以下规则：硬性余额、库存、法规模式和委托禁止项不可被个人对话覆盖；软性风险分歧可以补证、缩小规模、延后或申请机构治理层例外。例外必须指向具体软限额、金额、期限和责任人，不能借例外绕过账户硬约束。经理不同意研究员时可以不用其建议，双方记录均保留。

目标变更使旧母任务进入更新／取消流程。停止新子单后处理已挂订单，撤单回报之前仍允许出现合法成交；重新计算实际持仓和剩余任务，不能按旧目标再次完整下单。多人同时提出任务也不能重复预留同一笔现金。

考核按事前目标、可用资料和同类环境进行；短期结果与长期考核分开。月度工作复盘、季度正式考核可作为首轮配置；重大越权或支付风险即时处理。董事会可以改变预算、职责和任用，不能抹除离任者历史。频率与权重需做敏感性检验，不冒称现实机构统一制度。

## 5. 媒体是会调查和选择的组织

### 5.1 类型覆盖及边界

采用类型模板，首轮可合并部分人员，但保留任务与权限的不同。以下分类追求机制覆盖，不声称穷尽现实全部媒体。

| 类型 | 主要线索与工作方式 | 速度、成本和偏好 | 输出 |
| --- | --- | --- | --- |
| 通讯／快讯媒体 | 官方发布、公告、记者网络、现场消息 | 时效强，更新频繁；快讯可短但仍标来源 | 快讯、滚动更新、后续更正 |
| 证券与资本市场媒体 | 交易所公告、监管、投关、行业采访 | 关注上市主体与资本事件，重视出处 | 公告解读、公司新闻、市场专题 |
| 综合财经与调查媒体 | 多方采访、文件、数据、现场调查、匿名线索 | 调查耗时长，可能无法发布；编辑与核实成本高 | 深度报道、调查、解释性文章 |
| 行业垂直与价格资讯 | 企业样本、订单和报价、成交、渠道访谈 | 专业性和样本覆盖关键，有订阅及调查成本 | 行业数据、价格指数、供需报告 |
| 地方／区域商业媒体 | 本地工厂、项目、就业、工商活动、地方部门 | 距离近但视野有限，对地方关系有依赖 | 项目与现场报道、区域经营线索 |
| 海外／跨市场媒体 | 境外客户、政策、海外产业链和市场 | 时区、语言和转换延迟；可能误解本地语境 | 海外动态、跨市场分析 |
| 聚合平台／行情终端 | 接入上述信息，去重、分类、摘要和推荐 | 不因转发变成独立原始信源 | 资讯流、提醒、热点和专题 |
| 独立作者／自媒体／直播 | 公开资料、个人联系人、读者反馈 | 风格、能力和商业激励差异大，可认真核实也可逐热点 | 长短帖、视频文字稿、直播问答 |

另行建模三类非媒体主体：公司和监管的披露渠道、券商／买方研究部门、普通投资者与交流群。它们都能产生或传播信息，但不因此获得新闻机构身份。公司付费推广、观点文章、研究报告和独立新闻保留不同内容标签。

### 5.2 机构、记者与编辑的关系

媒体组织保存覆盖领域、订阅／广告／赞助等资金来源、费用预算、发布标准、受众、声誉和商业关系。记者保存自己的领域知识、联系人、日程、采访经历与选题；编辑有自己的判断和记忆，决定派工、补证、压稿、修改、发布或撤回。

调查记者可以主动提出选题；编辑也能派任务。小型自媒体可以由同一人物兼任作者与编辑，但必须显式保留其兼任关系，不能假装经过两个独立核实者。

媒体经营目标包括读者关注、持续订阅、准确性、专业声誉、发布时效和成本；各类型权重不同。不能把点击率或“推动股价变化”设为所有媒体唯一目标，也不预设所有媒体永久可靠。

### 5.3 选题和核实的具体流程

状态：发现线索 → 候选选题 → 提交／自批 → 资料收集与采访 → 可发布／待补证／放弃 → 编辑 → 发布 → 反馈 → 跟进／更正／撤回。

候选线索来自：订阅公告，异常价量但原因未知，行业价格变化，记者观察，读者提问或爆料，日历事项，既有报道的后续承诺，以及公开评论中的新争议。每条线索保留来源、首次出现时间和当时可见范围。

选题考虑受众相关性、新闻价值、证据可得性、时效、成本、记者能力、已报道程度和商业利益冲突。系统只生成候选及限制；记者与编辑决定实际取舍，允许选择冷门但重要的问题，或因证据不足不发稿。

核实动作包括读原始披露、检查报告期和版本、追踪转载首发、询问公司、联系反方或上下游、查可用行业样本、赴现场、复算公开数字。采访对象可以拒绝，匿名线索不自动变事实，两个同源转载不算两次独立确认。

订阅影响覆盖、便利、额外采访内容与到达方式，不把本来依法公开的公司文件设成必须购买媒体服务才有权查询。公开、付费、私人都不是可靠性的同义词。

事实核查者只用其可得材料，不读取上帝真值。错误报道可以产生，但记录“材料不足仍发表”或“错误推断”等实际路径；不能让任意生成的数字反向成为公司账目。

报道保留事件发生时间、发布时间、内容类型、作者／编辑、引用材料、转载谱系、版本及更正关联。独家采访不等于必须立即公开；获得许可、是否接受暂缓发布约定及约定违约都要形成行为事件。

## 6. 每个人的账号和交流方式

### 6.1 一个身份，多种空间

人物主页包含公开身份与发言、自己的收件箱／联系人、获授权的资产账户，以及上帝观察额外可见的记忆和决策轨迹。普通用户点开别人的评论，只能看到公开身份和发言，不自动看到资金、持仓、私聊或内部研究。

机构雇员要区分以个人身份发言与代表机构发言。媒体机构账号由明确的编辑授权发布；记者个人账号可以有不同表达。群组记录成员、邀请、加入／退出时间与历史消息可见规则；不能用今天加入群的资格无条件读到全部过去私聊。

### 6.2 渠道与生命周期

| 渠道 | 怎么开始 | 消耗与失败 | 结果如何进入世界 |
| --- | --- | --- | --- |
| 新闻／股票评论、回复 | 读到内容后决定发言，或在个人主页发布关联股票动态 | 写作与注意力，可能没人看到；可删除／更正但审计保留 | 发布到允许的范围；随后曝光、阅读、回应分别记录 |
| 私聊 | 已有联系人、公开可私信账号、实际收到的介绍 | 消息排队；接收方可以延后、拒绝、屏蔽 | 只投递给接收者，不自动更新其信念 |
| 群聊 | 已有群成员资格、公开群入口或邀请获准 | 消息量和注意力竞争；各成员不保证全部读到 | 按成员和时间权限可见，转述产生新消息 |
| 模拟电话 | 找到公开 IR 电话／既有联系人，提交拨打或预约 | 工作时段、忙线、接通失败、转接、双方时间占用 | 接通后各自逐轮作答；形成谈话与个人记录，后续纪要另发布 |
| 路演／业绩会 | 公告报名、组织邀请、岗位安排 | 名额、时间、提问机会和是否出席 | 参与者接收现场内容；直播／纪要按各自发布时间公开 |
| 模拟线下调研 | 提出问题、约访、获准、安排出行 | 路程、费用、时间、迟到／未赴约、受限区域、样本偏差 | 只观察实际可见的现场证据，访谈内容由对方提供 |

同步交流状态：申请 → 等待 → 接受／拒绝／改期／转交 → 预留双方时段 → 接通／出发到场 → 逐轮交流 → 完成／中断 → 记录与待办。发起者说“我已约到高管”只是提议，不是世界事实。

线下调研不要求先造三维城市。用地点、路程、开放时段、区域访问权和观察任务即可表达。例如观察门店客流得到有时间窗与抽样误差的计数，不能由一次看厂直接得到准确全年收入。

电话和调研的公司回答由相应岗位 Agent 产生：IR 可解释公开信息、纠正前提、转交；管理层可以根据自己知道的事实决定回答范围。每方只看到实际传递的内容。双方要分别接受和结束交流，不能让一个全知模型同时替双方作全部选择。

### 6.3 保留现实里的含糊、隐瞒和泄露

硬性信息边界限制角色能取得哪些资料；世界中的披露规范约束角色应该怎样说话，两者分开。角色不知道的秘密绝不进入其上下文。对于确实知道但不该外传的内容，沿用用户允许的泄露与歪曲设定：只有实际发送后才产生泄露事件，保留发送者、接收者、内容来源和后果。

普通解释、主观猜测、夸大、故意误导和已知秘密外传分别标记。检测与监管角色也只能根据自己得到的证据调查；上帝审计可以标明规范违背，但不能把审计发现自动广播给市场。把违规模式关掉的对照实验，应当显式记为场景变更，不能偷偷让所有角色永久完美合规。

外部消息里的文字永远不能改变系统权限或执行账目命令。模拟中允许说谎和泄露，不等于允许提示注入读取整个世界。

### 6.4 评论自然一些，但不凭空补经历

表达由人物说话习惯、与对方关系、当前情绪、持仓压力和当时话题共同决定。研究员也可以开玩笑，散户也可以认真分析；幽默程度与风险偏好、学历或资金量不是同一维度。

以下是为本项目写的原创表达示例，不是转载真实群聊：

- 面对认证新闻：“证书拿到了，订单还在路上，股价已经到厂门口了。”
- 对回款的担忧：“利润表先开香槟，现金流还在催款。”
- 自嘲观察情绪：“公告我看了三遍，仓位只允许我相信利好。”
- 调研预约失败：“电话没接通，先别把忙线写成重大利好。”
- 谨慎回应：“段子归段子，订单金额公告里真没写。”

不是每条评论都插段子。陈述“我刚打过电话”“上次亏过”必须关联真实的角色经历；若没有，不能为了风格自然把它写入事实记忆。需要模拟故意吹嘘时，标为当前发言的虚假自述，而非自动产生一段过去经历。首版仍不增加虚假自传记忆机制。

## 7. 为什么不同 Agent 会接触

### 7.1 采用什么项目的机制

| 参照项目 | 已核查机制 | 我方取用与不照搬的部分 |
| --- | --- | --- |
| Generative Agents | 地点附近的感知、注意力筛选、计划反应、忙碌检查、对话占日程及对象冷却 | 借鉴“共同活动带来机会”；不将其发起逻辑当作完整的双边预约制度 |
| OASIS | 关注网络内外的推荐、兴趣与时间因素、个体活跃时段 | 借鉴个人信息流和作者发现；不能用算法热度当可信度，也不照搬其规模性能结论 |
| Concordia | 时空观察、下一行动者，以及涉及他人自愿行为时单独征询 | 借鉴对方拥有决定权；账目、预约资源与权限由 Java 校验，不交给生成式裁判随口确定 |
| AgentSociety v1 cityagent | 需求触发、已有关系网选人、消息发送和地点选择 | 借鉴目的、关系和移动；其 online/offline 输出不能被误称为完整电话／线下系统 |

来源与精读定位列在文末。继续使用此前 CoffeeBench 的事件调度参照；这不是将多个 Python 项目整体拼进 Java。

### 7.2 六类接触机会

1. **信息接触**：关注公司／媒体、订阅主题、平台推荐或公开搜索，让某篇文章和作者进入视野。
2. **任务需要**：研究、授信、采访、生活资金问题，形成具体疑问并寻找可用渠道。
3. **已有关系**：过去同事、客户、行业联系人或有实际往来的朋友；关系网不是世界全体通讯录。
4. **共同活动**：同一会议、开放日、办公室或调研行程；共处只是机会，不自动听见全部谈话。
5. **真实引介**：某人实际发出介绍并获接收，对方愿意后形成联系；不会复制中间人的全部关系网。
6. **持续待办**：上次承诺回电、采访补证、合同到期或调查条件成立，触发再次联系。

每个机会保存：来自哪条可见记录、对象与渠道、议题、时间窗、预计耗时／费用、需要的授权及它为什么相关。先按渠道过滤可见范围、资格和资源，再让 Agent 选择；允许一个都不选。即时同步交流检查双方当前空闲与接待时段；异步私信允许发给忙碌的人并进入队列；预约检查计划时段，不能因为对方现在开会就禁止申请明天的调研。

公开资料可以由任意有该渠道访问权的角色主动查询；并非所有人已订阅、已读完或理解相同。公司公开咨询入口不因散户身份而彻底消失，成功接通与具体答复仍受正常工作安排影响。订阅内容和私人介绍是另外的访问条件，不能把所有信息都叫公开。

### 7.3 信息流和陌生人发现

候选池只包含当前可见、已经发布的内容。排序考虑主题、关注、时效、已读情况和人物偏好；另保留可配置的陌生来源探索机会，避免所有人被永久锁在初始关系圈。所有人看到同一快讯也可以是合理结果，不能为了差异强行藏起公开公告。

记录“有资格访问、进入推荐候选、实际展示、打开阅读、记入经历、形成信念、决定行动”这些不同阶段。没有打开的标题最多形成标题接触，不能自动获得文章全文内容。热度从实际曝光／阅读／互动统计，不凭空预设转发人数；平台推荐的反馈效应应单独分析。

## 8. 把已经研究的记忆接到行动上

沿用《Agent 上下文与记忆机制研究》六层结构，不另起一套“万能长期记忆”。

| 行动节点 | 继承的机制如何使用 |
| --- | --- |
| 准备读一条消息 | 先检查可见范围和时间；只把真实暴露的材料记为经历 |
| 决定联系谁 | 检索与当前问题相关的来往、专业信任、诚信判断和未完成承诺 |
| 形成判断 | 世界事实、对方声称、自己的信念分开；重复转载保留共同源头 |
| 决定交易 | 程序带入精确账户、挂单、任务版本和授权；按本次问题检索旧依据与反证 |
| 过了一段时间 | 回忆可得性衰减，审计原文不删除；过时信念要有更新时间 |
| 收到更正 | 更新可知版本，是否实际阅读、接受及纠正旧判断分别记录 |
| 定期复盘 | 根据多次具体经历调整习惯，保留版本；不因一次盈利把来源永久封神 |

来源专业能力、诚信、亲近程度、观点相近程度不是同一个分数。偏信可以影响先读谁、如何解读和是否找反证，但不能授予额外数据权限。遗忘影响提取概率和回忆内容可得性，不影响当前真实余额或已登记的有效法律／交易义务。

第一版仍只做遗忘、偏信和习惯变化；错误理解及传播错误说法可以存在，虚假自传记忆与自我合理化机制不悄悄加回。

## 9. 自主运行：什么时候醒，醒来做什么

### 9.1 一次行动周期

日程／事件／承诺唤醒 → 读取自己的必要状态 → 检查当前疑问与计划 → 形成有限候选 → 检索相关经历／当前公开资料 → 决定行动或等待 → 程序检查权限、时间、资源与版本 → 安排动作 → 得到回执或观察 → 更新经历、信念和待办。

返回“稍后继续”必须附下次时间或触发条件。等待是一种有效决定；技术超时、渠道拒绝和没有新证据是不同结果。真实模型调用延迟不等于模拟中的调查耗时。

### 9.2 事件如何触发不同岗位

| 事件 | 首先通知谁 | 后续是否进一步行动 |
| --- | --- | --- |
| 关注公司公告 | 已订阅者的信息队列、媒体线索队列 | 依据注意力和重要性决定何时读；不立即唤醒全世界完整推理 |
| 某调查疑问出现可用资料 | 登记该疑问的角色 | 对照原问题，可能结案、更新或继续追问 |
| 公司付款／生产异常 | 相应内部岗位与获权管理者 | 是否升级、修复、调整预算及披露分别决定 |
| 已收到赎回／支付义务 | 资金管理、经理与风险 | 形成现金计划及获批执行任务，不自动认定看空公司 |
| 订单成交／拒绝 | 执行者与账户状态 | 常规规则处理；重大偏差才请求更高层判断 |
| 联系回复／预约临近 | 实际接收者和参与者 | 阅读、接受改期、准备或取消；回执不等于阅读全文 |
| 没有新新闻的定时检查 | 有持续目标与研究覆盖任务者 | 主动寻找缺口，也可以继续休息或等待 |

### 9.3 可运行的首轮预算提议

下表为调试种子参数，单位为模拟时间，不是行业实测常数；每个主体从类型配置中取值并可不同。用于先验证“时间有限”是否真实改变行为，再用敏感性实验调整。

| 对象／动作 | 首轮提议 | 约束意义 |
| --- | --- | --- |
| 兼职个人 | 每交易日 20–45 分钟主动研究／交流，分配在其可用窗口 | 职业、收入与生活安排影响注意力，不能全天免费调查 |
| 活跃个人 | 每交易日 120–240 分钟相关主动活动 | 不保证有足够资金或专业能力 |
| 全职研究／记者 | 每工作日 240–360 分钟可排研究／采写时段，会议和出行从中扣除 | 机构有更多资源但仍需取舍覆盖 |
| 阅读快讯／长资料 | 约 1–3 分钟／10–30 分钟，随长度、技能和阅读深度变化 | 看到标题与完成全文调查不同 |
| 评论／短私信 | 约 0.5–2 分钟 | 允许简短自然交流，但不能无成本刷屏 |
| 电话交流 | 约 5–20 分钟，加准备与等待 | 同时预留双方注意力和日程 |
| 线下调研 | 半日至两日，加行程和费用 | 减少同期研究能力，不因请求成功就瞬间完成 |
| 一次唤醒 | 最多 4 次模型决策回合，最多 3 次连续调查动作 | 到限保存明确待办，不让单人无限占用运行 |
| 同步谈话 | 初始最多 8 次发言，任一方可提前结束 | 数值是成本上限；继续谈必须重新预约预算 |

执行算法可以持续响应已获授权的市场事件，不按每条行情调用 LLM。公司经营和账目照常运行，不受人物阅读预算拖停。人物原则上一次只能专注一个占注意力的同步活动；旅途中既有委托订单和机构执行员仍可继续工作，但本人不能同时参加两个电话会议。

同一主题同一联系人冷却初始设为一个工作时段；明确承诺回电、新证据或重大事件可触发重新联系。具体时长应属于场景配置，不把其他项目中的计数器直接解释为分钟。

### 9.4 时间、并发与中断

沿用此前实验时间方案：观察时点固定，动作有模拟完成时间；模型尚未返回时，到依赖它的行动点等待，界面仍可查看。超时产生技术失败或已规定的回退，不解释为公司破产。提交前再次检查人物状态、任务版本、有效授权和余额。

相同时点事件有记录的确定排序或种子化公平排序，不使用网络返回快慢决定谁先成交。精确回放使用记录的实际决定，不靠重新问同一个模型。

消息进入队列，不递归直接调用对方。重复消息按标识去重；已读回执不触发新的完整交流；普通提醒合并处理。每次往返推进时间，同一因果链有预算、截止和无进展终止条件。高优先风险与已承诺回复有专门通道，避免被热门帖子淹没。

### 9.5 长行动的取消与失效

电话、出行和调研不能只在最初排程时检查权限。动作开始、进入受限地点／读取新材料，以及产生新的受限操作效果之前都要复核相关授权、预约状态和任务版本。

| 当前阶段 | 授权撤销、角色停用或对方取消后如何处理 |
| --- | --- |
| 尚未开始 | 取消待执行步骤，释放未使用时段和未支出的预留资金；已支付且不可退的订金按合同保留成本 |
| 电话／会议进行中 | 结束或中断后续交流，不再产生新发言／新材料；已实际说出的内容和已用时间仍保留 |
| 已出发或现场调研进行中 | 取消尚未获准的访问与调查，按行程规则安排返程或另行等待；已经发生的交通、时间和合法观察不回滚 |
| 已完成，回执或摘要迟到 | 根据动作标识识别已经完成的结果，只补记录，不重新执行；不得把旧授权用于新行动 |

“解除预留”与“退回已支出费用”是两种事件；实际耗时不会因取消变回可用过去时间。角色结束任务仍需清理其预约和未开始动作，不能留下永久占用。金融挂单另外走撤单／成交确认流程，已经合法成交不能由人物停用回滚。

## 10. 上帝视角要能查到的内容

人物页新增活动时间线、收件箱、联系人、当前任务与注意力使用；机构页显示岗位交接、目标版本和冲突；媒体页显示线索、采写进度、证据、编辑意见、发布与更正；世界图可切换经营、资金、组织、社交和传播。

点击一次行动，应显示：为何醒来；当时能看到什么；实际读了什么；检索到了哪些经历；哪些未处理任务仍有效；提出了什么动作；谁接受／拒绝；花了多少模拟时间与钱；执行结果；后续影响。这里记录结构化决定、理由摘要和工具结果，不要求展示模型隐藏推理链。

世界图上的边至少区分：合同与付款、证券持仓、任职、认识／引介、消息投递、实际阅读和转载。来源关系可查不等于因果已证明；股价影响必须另用实验检验。

首轮实现仍按 Java 世界状态、行为与调度、交流投递、观察投影分层。已有撮合和账户保持确定性；公司、媒体、人员不统一继承“一个人一个资金账户”的旧交易者模型。新增模板可以换行业或媒体定位，但不绕过共享时间、资源、权限和审计规则。

## 11. 验收场景

| 场景 | 必须成立的结果 |
| --- | --- |
| 十家公司互无采购合同 | 仍能通过外部客户、供应商与共同条件正常经营，禁止自动生成彼此交易 |
| 外部需求改善但订单尚未签订 | 预期可变化，收入和现金不能提前到账 |
| 现实资料出现新版本 | 候选配置可更新，旧运行的已发生合同和账目不被覆盖；受控导入有显式事件 |
| 只有记者收到匿名线索 | 其他人不自动知道；记者必须实际联系、调查或发布才传播 |
| 多家媒体转载同一报道 | 表现为传播增加，不自动变成多项独立证据 |
| 普通投资者联系公司 | 有公开渠道，可收到正常解释或拒答；不保证获知秘密，也不因身份直接禁止尝试 |
| 线下看见忙碌车间 | 只产生有范围的观察，不自动得到精确产量、收入或内部订单 |
| 一人申请另一人参加访谈 | 对方拒绝、改期或缺席均有效；不能单方写成已完成 |
| 消息进入收件箱但未读 | 不能在交易理由里使用全文；回执和实际阅读不同 |
| 角色忘记旧报道但有未完成挂单 | 旧报道检索可衰减，余额、冻结和有效订单仍准确 |
| 公开玩笑含“我刚调研回来” | 必须关联真实经历，或明确成为当前虚假自述；不创造过去记忆 |
| 私人说出已知秘密 | 仅实际接收者先获知，形成泄露记录；不会修改原事实或广播全市场 |
| 经理出差，交易员有有效母任务 | 经理时间被占，既有获批执行仍可继续；新授权需正确流程 |
| 风控暂停时订单部分成交 | 已成交记账，未成交按流程取消，不能假装全部撤回或重复买入 |
| 两个角色热衷互相回复 | 队列、预算、时间推进和终止条件防止同一时点无限调用 |
| 相同信息面对不同身份与约束 | 可以产生不同行动，也允许一致；不以强制反向交易制造多样性 |

软指标包括曝光到阅读转化、主动调查有效率、接触渠道分布、对话结束原因、证据来源多样性、错误更正延迟、角色活动差异和资源成本。收益不是社会行为真实度的唯一指标。后续用相同模型和预算做多次对照，区别人物差异、信息流算法和模拟程序缺陷。
