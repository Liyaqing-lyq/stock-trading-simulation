## 课程撮合内核稳定口径

- 金额BigDecimal（金额2位、成本价4位）、数量long，不用double记账；引擎锁→账户锁，行情广播/CSV/GUI更新在锁外，GUI用Platform.runLater。详见AGENTS.md，不静默更改。
- 价格优先、同价FIFO，被动方价格成交；限价剩余挂簿，市价剩余撤销；资金/股份按订单冻结，实际成交/撤销正确释放，收盘清理挂单。不能假设“等于最新价”必能成交或必不能成交，应看实际对手报价和簿状态。
- 初始持仓、开盘首推行情、MarketDataPublisher订阅不可漏；持续报价角色须管理旧挂单与冻结，避免无成交陈旧单占满额度。沿AbstractTradingAgent已有撤单/报价管理机制。
- 收益率基准是初始资金加初始持仓成本；初始权益不能因注资、分红或业务亏损重置。最大回撤基于权益峰谷，胜率基于盈利平仓数/平仓数。

## 扩展世界稳定口径

- 唯一WorldRuntime、WorldJournal、WorldScheduler和权威现金/证券账。候选批次持久确认后发布；金额、股份、订单、工时、待办和相关业务变化同批恢复，CSV只用于导出核验。
- 真实原命令逐帧重演，不能只验证JSON结构/内部摘要。旧档继续原行为和序列化契约；新规则显式冻结，不隐式迁移。兼容验证用真正旧实现写/读/续写，与新实现交叉，不用新类冒充旧客户端。
- 人物会话绑定观察任职；执行权限取观察绑定与执行时资格的交集。开始/完成、授权/实际付款、发布/投递/阅读/记忆/相信/行动分别核验，不让界面SCHEDULED冒充已完成。
- 机构四岗沿真实研究阅读→经理目标→风控→经理确认→交易员子单。目标是账户标的绝对股数；改目标先撤净旧单，再以当前真实持仓建立新基点。截止、审核、任期各有真实任务；流程只存元数据和订单链接，不复制账。
- 决定配置、准确输入、原回执、用量和一次结算冻结。重试沿原观察/屏障，恢复代次由宿主明确接续；完整尝试身份去重，有界回执队列在持久成功后移除。未知费用保守结算，拒绝也保留真实审计；新进程不自动开旧会话门闸。
- 角色输入不得依赖God位置、内部摘要或私有来源。材料权限来自实际章程/任职/群成员，真实读完与Recall资格分别核验；历史已合法投票不被未来遗忘或离职抹除。未读到不等于不存在，转述同源不变独立证据。
- 分红D0只登记真实remaining权益，不支付；除息才生应付。持有人减值不消灭公司债务；减值转回、付款、资本流基于真实事件。估值只计现金一次，缺行情保留缺项；TWR用真实流前/后估值链接，组织净资产包含实际经营资产负债。
- 工程、银行、研发等实验政策明确标EXP，不把参考数、合成例子或尚未核实的来源线索称为现实校准/合规证据。机制测试、模型行为实验与经验有效性分列；缺维不补零、不为通过测试伪造业绩或流动性。
